# 004 - 工具执行管道

> 状态: 实施中 | 最后核对: 2026-08-26

## 1. 目标与非目标

目标是提供编码 Agent 的真实 `read / glob / grep / write / edit / bash` 工具面，同时把参数校验、工作区边界、权限、WAL、取消、输出归档和外部修改冲突做成不可绕过的统一管道。

本文不把 bash 当作安全沙箱；系统级 seatbelt/bwrap 隔离属于 006。当前 bash 已安全收窄环境、受权限门约束，但仍是高权限工具。

## 2. 统一执行序

```text
tool.call（模型原始请求入账）
  → 查注册表（未知工具拒绝）
  → AJV JSON Schema 校验（schema 自身异常也拒绝）
  → permission.evaluated（结构化权限类别、模式与规则；异常 fail-closed）
  → 必要时人工审批
  → tool.intent fsync
  → 按 parallel / serial / exclusive 分组执行
  → 输出限额与 ArtifactStore 归档
  → tool.result（成功、失败、超时、取消都补终态）
```

只读工具 `read/glob/grep` 可并行；`write/edit` 串行；`bash` 独占。串行工具不会提前写下一条 intent，避免日志声称尚未开始的副作用已经启动。

## 3. 工作区路径守卫

所有文件路径先相对 session cwd 词法解析，再经真实路径校验：

- 拒绝 `..`、绝对路径等越出工作区的输入；
- macOS `/tmp` 等别名先 canonicalize，避免合法路径误判；
- 读取已有路径时对最终 `realpath` 再校验，阻止 symlink 逃逸；
- 写入拒绝最终目标 symlink；新文件校验最近存在祖先，并在 rename 前重新校验父目录；
- 不跟随 glob 的符号链接。

006 上线后再用 OS 沙箱覆盖 Node 无 `openat` 时无法彻底消除的恶意并发 symlink race。

## 4. Read / Write / Edit 契约

`read` 返回：规范化相对路径、SHA-256、字节数、带行号正文。仅接受有效 UTF-8 文本，拒绝 NUL 二进制与超过 16 MiB 的单文件。

`write`：

- 新文件不传 `expected_sha256`；
- 覆盖已有文件必须传最近一次 `read` 返回的 SHA-256；
- 文件已变、更早版本被删除、未读直接覆盖均报 `tool.write_conflict`；
- 同目录临时文件以 `wx` 创建，写入后 `fsync(file) → rename → fsync(dir)`；
- 失败路径清理临时文件，保留原文件权限位。

`edit` 除 revision 必填外，`old` 必须恰好出现一次；零次报 `tool.edit_no_match`，多次报 `tool.edit_ambiguous`。编辑也走同一原子写管道。

## 5. Glob / Grep

- 首选系统 `rg`，继承其速度、隐藏文件与 gitignore 语义；默认排除 `.git` 和 `node_modules`。
- `glob` 用 `rg --files --glob`；结果稳定排序并有显式数量上限。
- `grep` 返回 `path:line:column:text`，支持 glob、路径、大小写与结果上限。
- `rg` 缺失时，glob 降级为 `fast-glob + ignore`；grep 降级为受文件数量/大小约束的 JavaScript RegExp，并在结果中标注 fallback 引擎。
- fallback 是正式可搬移能力，不依赖 SparkWork 宿主包。

## 6. Bash

- 使用用户 shell 的非交互 login 模式，cwd 固定为工作区。
- 子进程建独立进程组；AbortSignal 终止整组而非只杀父 shell。
- stdout+stderr 总量默认限制 8 MiB，超限终止，避免内存失控。
- 默认从子进程环境移除名称含 API_KEY / KEY / TOKEN / SECRET / PASSWORD / CREDENTIAL 等凭据变量；Provider key 永不自动暴露给模型 shell。
- bash 定义为 permissionClass=command + destructive + approval always；无审批通道时拒绝，且不能创建 session grant。

## 7. 已验证用例

- 词法路径逃逸、读 symlink 逃逸、写 symlink 均拒绝。
- stale overwrite、无 revision 覆盖、删除后写入均冲突。
- 原子写成功且无临时文件残留；精确编辑歧义拒绝。
- glob/grep 真实结果；shell 凭据环境过滤。
- shell 进程组取消返回 AbortError。
- 工具参数、权限、超时、制品管道失败均有 `tool.result`。
