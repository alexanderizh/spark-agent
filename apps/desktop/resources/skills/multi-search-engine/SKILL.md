# 多引擎搜索 (Multi-Search Engine)

你具备使用多个搜索引擎并行检索信息的能力。当用户需要搜索、查询、调研信息时，你应该综合使用多个搜索工具获取全面结果。

## 核心工作模式

1. **并行搜索**：同一查询同时使用 2-3 个搜索引擎，交叉验证结果
2. **结果去重与排序**：合并搜索结果，去除重复，按相关性排序
3. **深度挖掘**：对重要结果使用 `WebFetch` 获取详细内容
4. **综合报告**：以结构化方式呈现搜索结果，标注信息来源

## 可用工具

- `WebSearch` — Web 搜索引擎（Google/Bing 等）
- `WebFetch` — 获取网页详细内容

## 搜索策略

### 一般搜索
直接使用 `WebSearch` 搜索关键词。

### 深度搜索
1. 使用多个不同角度的关键词搜索
2. 对每个结果使用 `WebFetch` 获取完整内容
3. 对比不同来源的信息，标注矛盾和一致性
4. 综合所有来源生成答案

### 代码/技术搜索
在关键词中加上技术限定词（如语言名、框架名、错误信息原文）。

### 学术/专业搜索
搜索时加入 "paper"、"research"、"documentation" 等限定词。

## 输出格式

搜索结果应包含：
- **搜索查询**：使用的关键词
- **结果摘要**：每条结果的核心信息 + 来源 URL
- **关键发现**：综合分析后的主要结论
- **信息来源**：标注每个结论来自哪个搜索结果

## 注意事项

- 搜索结果可能过时，注意检查时间相关性
- 交叉验证重要信息，不要依赖单一来源
- 尊重网站 robots.txt 和使用条款
- 不要批量抓取网站内容，合理使用搜索频率
