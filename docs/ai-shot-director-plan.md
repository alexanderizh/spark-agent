# AI 分镜导演台开发计划

> 状态: 实施中 | 最后核对: 2026-06-20

## 背景

Canvas 当前已经具备项目、画布、素材、任务、影视资产中心和提示词库能力，但用户在生成图片或视频前，仍缺少一个可视化表达“人物站位、物件关系、镜头方向、景别、运镜轨迹”的工作台。该功能用于把导演的空间调度意图转为可供 AI 生图或视频模型使用的结构化提示词。

## 目标

- 在 Canvas 工作区内提供“分镜导演台”入口。
- 支持以分镜为单位编排人物、物件、镜头和运镜关键帧。
- 第一阶段用 2.5D 俯视导演台验证工作流，数据结构按 3D / 运镜扩展设计。
- 生成可编辑、可复制、可插入画布的图像 / 视频提示词。
- 后续平滑升级到 Three.js 轻量 3D 预演和多镜头时间线。

## 方案三落地拆解

### 阶段一：画布内分镜导演台 MVP

- 在 Canvas 底部工具栏新增“分镜导演台”入口。
- 提供单镜头 2.5D 俯视编排面板。
- 支持角色、物件、镜头参数、运镜关键帧的结构化表单。
- 提供俯视布局预览，展示站位、朝向、镜头视锥和运镜路径。
- 生成静态图提示词与视频镜头提示词。
- 支持将生成提示词插入为 Canvas 文本节点。

### 阶段二：多镜头分镜管理

- 支持 Shot 列表、镜头复制、镜头重排、镜头状态保存。
- 将导演台数据沉淀到项目 metadata 或独立资产中。
- 支持从影视资产中心的角色 / 场景 / 道具资产引用数据。
- 支持批量生成分镜提示词。

### 阶段三：轻量 3D 预演

- 引入 3D 低模人物、物件和 Camera Rig。
- 提供编辑视角与镜头视角双视图。
- 支持焦距、FOV、镜头高度、对焦目标。
- 支持关键帧路径插值和运镜模板。

### 阶段四：AI 视频导演工作流

- 形成多镜头时间线。
- 支持镜头起止帧、动作段落、速度曲线。
- 可把分镜提示词直接发送到 Canvas 的视频生成任务节点。
- 支持导出 storyboard / JSON / prompt pack。

## 第一阶段实现边界

本轮先落地阶段一。为控制风险，不新增数据库表和重型 3D 依赖，不改 Canvas 节点持久化主流程；先通过工作区浮层、项目 metadata 和现有图片节点链路完成核心闭环。

## v0.2 核心闭环

- **操作优化**：俯视图内直接拖拽人物、物件、镜头和关键帧；点击预览元素后高亮对应表单；显示运镜路径和镜头目标线。
- **数据持久化**：导演台草稿按 board 写入 `project.metadata.shotDirector.boards[boardId]`，避免关闭面板后丢失。
- **导演台截图**：用 Canvas 渲染一张干净的俯视构图图，保存成本地图片节点，并同步插入当前提示词文本节点。
- **UI 优化**：将镜头模板、保存状态、截图动作、提示词模式集中到工作流按钮上，减少纯表单操作压力。
- **智能辅助**：提供构图健康度、问题提示、重排站位、贴三分点、自动层次、镜头看向选中对象等快速动作。
- **多镜头管理**：提供 Shot 时间线，支持镜头切换、新建、复制、删除、命名和时长编辑。

## v0.3 交互与预演优化

- **工作台布局**：重构为左侧资产编排、中间预演、右侧检查与输出的三栏结构，避免表单和预览互相挤压。
- **全屏与滚动**：导演台默认使用画布可用区域全屏运行；左栏、中间预演、右栏各自具备合理滚动边界，窄屏降级为单列滚动。
- **3D 预演模式**：新增默认的透视 3D 预演视图，人物和关键帧按画面深度缩放，地面使用透视网格表达空间关系；保留俯视编排视图用于精确拖拽。
- **溢出修复**：统一输入控件、卡片和工具条的最小宽度策略，修复左侧卡片、按钮和表单在窄宽度下溢出的问题。
- **浮层体系统一**：项目资产中心、底部编辑浮层、文生图 / 图生视频操作面板、画布 Agent 对话面板均提供一致的全屏入口；全屏时固定头部和底部操作区，中间内容区独立纵向滚动，操作按钮避开窗口拖拽层。

## 数据结构方向

第一阶段组件内部使用以下概念：

- `subject`: 角色或物件，占位位置为 `x/y/z`，含朝向、描述和画面层次。
- `camera`: 镜头位置、目标点、景别、镜头角度、焦距和构图策略。
- `keyframe`: 运镜关键帧，描述时间点、相机坐标、看向目标和运动类型。
- `prompt`: 从场景、主体、镜头和运镜数据组合出的 AI 提示词。

导演台 v0.2 写入 Canvas 项目 `metadata.shotDirector`，避免过早做 schema migration。计划结构：

```ts
type ShotDirectorMetadata = {
  version: 1
  boards: Record<string, CanvasShotDirectorDraft>
}
```

## 验收标准

- 用户可从 Canvas 底部 Dock 打开分镜导演台。
- 用户可添加/删除角色和物件，并通过表单或俯视图拖拽调整位置、朝向、描述。
- 用户可设置镜头景别、角度、焦距、构图和运镜关键帧。
- 用户可保存当前 board 的导演台草稿，下次打开仍可继续编辑。
- 用户可一键生成导演台截图，并将截图和提示词插入当前画布。
- 用户可看到构图健康度，并通过智能动作快速修正站位、层次和镜头目标。
- 用户可在同一 board 下管理多个镜头，并在镜头之间切换编排状态。
- 用户可在 3D 预演与俯视编排之间切换，并在两种视图下拖拽调整空间关系。
- 导演台面板可伸缩，三个工作区可滚动且不发生横向溢出。
- 面板能实时生成图片和视频提示词。
- 生成提示词可插入当前画布，成为可继续参与 AI 任务的文本节点。
- TypeScript 构建通过。
