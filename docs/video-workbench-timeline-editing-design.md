# 视频工作台轨道剪辑交互设计

> 状态: 已落地 | 最后核对: 2026-07-14

## 目标

视频工作台采用桌面视频剪辑软件的直接操控方式：时间型剪辑在 V1 轨道上完成，右侧面板仅承载转码、变速、倒放、等分切割和画面裁剪等参数型处理。

## 已落地交互

- 工作台外壳高度跟随应用动态视口，不再受 `980px` 上限限制。
- V1 源视频片段显示明确的左右修剪手柄；拖动手柄实时更新入点、出点和选区时长。
- 播放头支持点击/拖动定位；方向键按 `0.1s` 微调，`Shift + 方向键` 按 `5s` 跳转。
- `I` / `O` 或工具栏按钮可把当前播放头设置为入点 / 出点。
- `Cmd/Ctrl + B` 或“分割”按钮在播放头处把当前选区导出为前后两个片段。
- 支持“快切”（按关键帧无损裁切）和“精切”（重新编码精确裁切），选区可从轨道直接导出。
- 轨道保留缩放、关键帧定位、手动帧标记和批量提取能力；图标按钮提供可访问名称，修剪手柄支持键盘调整。
- 产物生成后自动切换到“产物检查”页，避免用户继续在剪辑参数面板中寻找结果。

## 边界与约束

- 当前实现是单源视频 V1 轨道，剪辑结果以新产物写入工作台，不覆盖源视频。
- 修剪区间最短为 `0.1s`，手柄不会交叉或超出源视频时长。
- 分割要求播放头位于选区内部，且两侧都满足最小时长。
- FFmpeg 未就绪时仍可定位、设置入出点和缩放，但导出与分割动作保持禁用。

## 后续范围

多视频轨道、音频轨道、片段重排、磁吸、波纹删除、转场和完整 EDL 合成不属于本轮；这些能力需要先扩展持久化时间线模型与合成管线，不能只在渲染层模拟。
