# 无限画布右键菜单优化规划

> 状态: 已落地 | 最后核对: 2026-07-10

## 背景

无线/无限画布的右键菜单存在两个主要问题：

- 一级菜单和二级菜单过长，在画布顶部或底部触发时可能溢出屏幕，影响点击。
- 多选多个节点后缺少稳定的选区右键入口，创建组、加入组、移出组、合并为组合图等批量动作不够直接。

## 已落地调整

- 抽出 `canvasContextMenuModel`，统一计算右键菜单位置、最大高度、二级菜单展开方向。
- 空白画布/选区右键菜单根据视口边界自动夹紧位置，底部触发时向上展开，右侧触发时二级菜单向左展开。
- 多选节点时，右键选中节点会打开选区菜单，支持复制、创建组、合并为组合图、加入选中的组、移出组、解散组、锁定/解锁、置顶、删除。
- 多选多个顶层内容节点后执行“合并为组合图”时，会先创建组，再立即基于新组生成合成图。
- 节点右键菜单新增“选区操作”分组，把多选创建组、合并组合图收入口径；“任务节点”调整为“生成任务”，二级菜单按图像、文本、视频、音频能力分段。

## 菜单分组原则

- 选区/节点操作：复制、编辑、打开面板、批量复制。
- 生成任务：图像、文本、视频、音频、流水线动作。
- 分组与组合：创建组、加入组、移出组、解散组、合并为组合图。
- 资源与导出：下载、保存到资源库、从资产选择。
- 状态与层级：确认采用、标记待更新、锁定、置顶。
- 危险操作：删除节点、删除选区、删除连线。

## 后续建议

- 将节点右键菜单从 Ant Dropdown 逐步迁移到同一套自绘菜单模型，彻底统一一级/二级菜单的定位、滚动和键盘行为。
- 给生成任务二级菜单增加能力搜索或最近使用区，避免能力继续增长后再次变长。
- 将选区菜单的可用性提示补充为 tooltip，例如“只支持多个未入组顶层节点创建组”。
