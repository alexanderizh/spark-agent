# 权限审批与会话导入界面优化

> 状态: 已落地 | 最后核对: 2026-07-12

## 目标

- 权限审批默认面向普通用户展示操作意图、目标和风险，不直接展示工具 JSON 参数。
- 会话导入在扫描、选择、预览和导入完成各阶段提供清晰的状态反馈。

## 已落地交互

### 权限审批

- 输入区上方的内联审批卡与独立审批弹窗共用同一套内容组件。
- `Edit` 类操作默认仅展示“修改文件”、目标文件路径和操作说明。
- 命令、文件读写、搜索和网络访问会映射为自然语言标题及关键参数。
- 完整 JSON 参数保留在“查看技术详情”折叠区，便于技术用户审核。

### 会话导入

- 扫描阶段新增扫描波纹与旋转指示动效，并支持 `prefers-reduced-motion` 减少动效。
- 选择页增加扫描结果总数、已导入跳过提示和更明确的当前行状态。
- 会话行支持键盘打开预览。
- 预览区使用对话气泡区分用户与助手消息，并保留来源、工作目录和角色信息。

## 验证

- TypeScript 渲染端与 Electron 主进程类型检查通过。
- 权限摘要单元测覆盖 `Edit` 脱敏摘要和 Shell 命令摘要。
