# 后期待开发已隐藏内容

本文档记录了为了简化项目而临时隐藏或移除的功能，供后续开发参考。

## 一、完全移除的功能（Codex 内核）

以下 Codex 相关代码已被完全移除，不再支持：

### 1. Protocol 层

**packages/protocol/src/ipc/index.ts**
- `SessionAgentAdapter` 类型移除 `'codex'` 选项
- `SessionPermissionMode` 类型移除 `'codex-default'`、`'codex-auto-review'`、`'codex-full-access'`
- `ProviderProfile` 接口移除 `codexApiKind` 字段
- `ProviderCreateRequest`/`ProviderUpdateRequest` 接口移除 `codexApiKind` 字段
- Skill 相关接口移除 `'codex'` 源类型

**packages/protocol/src/schemas/index.ts**
- `LocalSkillSourceSchema` 移除 `'codex'` 选项
- `SessionAgentAdapterSchema` 移除 `'codex'` 选项
- `SessionPermissionModeSchema` 移除 codex 相关权限模式
- 移除 `CodexApiKindSchema` 定义
- Provider 请求 Schema 移除 `codexApiKind` 字段

**packages/protocol/src/events/index.ts**
- `ProviderId` 类型移除 `'codex'` 字面量
- 注释中移除 Codex Adapter 相关描述
- `adapterKind` 字段保留 `'codex'` 作为类型兼容，但运行时不支持

### 2. UI 层

**apps/desktop/src/renderer/design/views/SettingsView.tsx**
- 移除 `CodexApiKind` 类型定义
- 移除 `ProviderForm` 中的 `codexApiKind` 字段
- 移除 Provider 编辑面板中的 "OpenAI API 类型" 选择器
- 移除 `normalizeCodexApiKind` 函数
- 移除 `CODEX_RUNTIME_PERMISSION_OPTIONS` 常量
- 更新权限模式选项函数仅返回 Claude SDK 选项

**apps/desktop/src/renderer/design/views/ChatView.tsx**
- 移除 `ADAPTER_OPTIONS` 中的 Codex 选项
- 移除 `ADAPTER_LABELS` 中的 Codex 标签
- 移除 `CODEX_PERMISSION_MODE_OPTIONS` 常量
- 更新权限模式选项函数仅返回 Claude SDK 选项
- 更新默认权限模式从 `'codex-default'` 改为 `'claude-ask'`
- 更新 `getProviderAdapterKind` 函数始终返回 `'claude-sdk'`
