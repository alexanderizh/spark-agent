# 画布「剧本文稿 → 影视产物」全流程生产设计

> 状态: 待开发 | 最后核对: 2026-06-20
>
> 范围：把无限画布从「单点 AI 生成 + 影视资产中心」升级为一条
> 「立项与视觉总设定 → 文稿/章节 → 剧本 → 实体资源 → 设定图卡 → 分镜（按秒）→ 关键帧 → 逐段视频 → 成片」
> 的**分层人机协作生产流水线**。每一步都可由「人编辑 ↔ agent 基于人的已确认结果续生成」双向协作完成，
> 尽量以画布节点 + 右键一键编排呈现，内置提示词模板库作为全流程引擎。
>
> 本版本对前一版**线性流程做了重新梳理与合理性评估**（见 §3），核心改动：分三层、实体资源与镜头风格解耦、
> 流程由「线性链」改为「DAG（图卡与分镜可并行，汇聚于关键帧）」、新增立项/视觉总设定与阶段闸门。

## 1. 背景与目标

当前无限画布已具备：节点/边血缘、影视资产中心（剧本/角色/场景/道具/特效/分镜分组/提示词库）、
镜头语言与表演提示词库、媒体模型 manifest 与任务生命周期（文生图/图生图/图生视频/文生视频…）。
缺一条把「一部小说/长文稿」端到端推进到「成片」的**主线流水线**，尤其缺：超长文本工程化管理、
阶段间可执行编排、人机双向协作契约、按秒分镜+关键帧、把「角色/场景/关键帧/提示词」一起喂视频模型逐段产出。

目标：在**最大化复用既有数据结构与节点系统**前提下，补齐「文稿工作台 + 分层流水线编排 + 协作契约 +
内置提示词引擎」，让人与 agent 在同一张画布（加一个独立文稿工作台）上协作完成全流程。

## 3. 流程合理性评估与优化决策（本次重点）

对「章节→剧本→资源→图卡→分镜→关键帧→视频」这条原始线性流程逐项评估，发现并修正以下问题：

| # | 原始流程的问题 | 优化决策 |
|---|----------------|----------|
| P1 | **类目混淆**：把「角色/场景/道具/特效」（从文本抽取的**实体**）与「运镜/画面/动作设计」（不在文本里的**创作/风格决策**）放进同一「资源」步骤。 | **分两类**：实体资源（从剧本抽取）与镜头/画面/动作**风格预设**（项目级一次性设定、随时复用），分属不同层。 |
| P2 | **缺「整体设计」**：用户原始诉求里的「整体角色设计/整体视觉设计」无落点，视觉风格散落在 `series.visualStyle`。 | 新增 **S0 立项 + 视觉总设定（Style Bible）**：类型/媒介(2D/3D/写实/动画)/色彩/比例/节奏基线，全流程继承。 |
| P3 | **伪线性**：实际上「设定图卡」与「分镜」在资源确认后**可并行**，二者汇聚于「关键帧」。线性表述会误导实现与排期。 | 流程改为 **DAG**：资源确认后，图卡线与分镜线并行推进，在关键帧汇聚（§4 图）。 |
| P4 | **图卡 ≠ 关键帧**被混为一谈：设定图卡是**可复用的设计参考**（角色/场景定妆），关键帧是**镜头专属帧**。 | 明确两种角色：图卡是一致性锚点（设计层），关键帧消费图卡产出镜头帧（生产层）。 |
| P5 | **缺一致性主线**：角色/场景/风格在全片的一致性是成败关键，原流程只在角色 I2I 里零散提及。 | 抽出 **§9 一致性贯穿性机制**：基准图 + I2I + 锁定项 + 首尾帧衔接 + 风格继承。 |
| P6 | **按秒切分依据不明**：agent 凭什么定每镜几秒？ | 明确切分输入：**对白朗读时长 + 动作节拍 + 节奏基线**三者，人可微调（§S6）。 |
| P7 | **缺阶段闸门**：下游可能基于未定稿上游生成，造成返工。 | 层与层之间设 **confirm gate**：下游默认只读上游 `confirmed` 内容（§9 协作契约）。 |
| P8 | **缺后期收口**：到「视频片段」就停了，没有拼接/配音/字幕/导出。 | 新增 **S9 后期与导出**（本期先做顺序拼接 + 转场占位，音轨/字幕后续）。 |
| P9 | **跨章共享边界含糊**：哪些资源跨章、哪些章内。 | 明确：**实体资源 + 风格预设 = 项目级跨章共享**；剧本/分镜/关键帧/视频 = 章内（board 内）。 |

## 4. 优化后的整体流程（三层 + DAG）

把流程显式分为**三层**，层内可迭代，层间有确认闸门：

- **A 设定层（项目级，一次性 + 持续微调）**：S0 立项与视觉总设定、镜头/画面/动作风格预设。
- **B 内容层（文稿驱动）**：S1 文稿/章节、S2 章节→剧本、S3 剧本→实体资源（项目级共享）。
- **C 生产层（按章/按集，DAG）**：S4 资源→设定图卡 ∥ S6 剧本→分镜 → S7 关键帧 → S8 逐段视频 → S9 成片。

```text
A 设定层(项目级)         B 内容层(文稿驱动)              C 生产层(按章, DAG)
─────────────────       ───────────────────            ────────────────────────────────
S0 立项+视觉总设定 ──┐    S1 文稿工作台                   ┌─ S4 资源→设定图卡(角色三视图/表情/
  (Style Bible)     │      └分片导入/分章/编辑             │     远近/服装/五官/武器道具; 场景/道具)
                    │            │                        │            │(一致性锚点)
S5 风格预设 ────────┤      S2 章节→剧本(右键一键)          │            ▼
  运镜/画面/动作     │        ├ 剧本内容(场次)             ├─────► S7 关键帧(首/尾/中, 消费图卡)
  (项目级可复用)     │        └ 抽取/合并→S3               │            ▲      │
                    │            │                        │            │      ▼
                    └──继承──►  S3 实体资源(项目级共享) ───┘     S6 剧本→分镜(按秒)  S8 逐段视频(I2V)
                               角色/场景/道具/特效           引用资源+风格预设        │
                                                                   │                ▼
                                                                   └──────────► S9 成片(拼接/导出)
```

**闸门（confirm gate）**：A 定稿才进 B 的大规模生成；S3 资源 `confirmed` 才进 C；S6 分镜 `confirmed` 才出关键帧/视频。
未定稿也能预览试跑，但下游正式生成只读已确认内容（§9）。

## 5. 画布承载：节点 vs 工作台 + 泳道

**两类承载**（避免长文本拖垮画布）：

- **重文本/强结构化/批量编辑** → 独立「**文稿工作台**」面板；画布上只放**轻量引用节点**（标题+摘要+状态，双击进工作台）。
  适用：整部文稿、整章原文、整本剧本。
- **流水线生产对象** → 直接画布节点（可连线/生成/产物）。
  适用：章节节点、场次剧本节点、各类资源/风格设定节点、设定图卡、分镜、关键帧、视频。

**泳道布局**：

- **一章一 board**（绑定 `chapterId`/`episodeId`）：该章的剧本→分镜→关键帧→视频在同一画布展开。
- **board 内按阶段分泳道（Frame/Group）**：剧本区 / 分镜区 / 关键帧区 / 视频区，下游产物默认排到下一泳道。
- **项目级共享资源**（角色/场景/道具/特效 + 风格预设 + 视觉总设定）存 `project.metadata.film`，
  在任意章 board 以**引用节点**出现，编辑回写、全局同步。

## 6. 节点模型

优先用 `data.subtype` + `data.pipelineRole` + `displayCategory` 区分语义，**不轻易新增底层 `CanvasNodeType`**：

| 流水线对象 | 底层 type | `pipelineRole` | 承载数据 | 主要边 |
|------------|-----------|----------------|----------|--------|
| 视觉总设定 | `prompt` | `style_bible` | `series` + 全局风格 prompt | →（被所有生成继承） |
| 章节 | `text` | `chapter` | `asset(kind=chapter)` 引用 + 摘要 | → 剧本 |
| 剧本（场次） | `text` | `screenplay` | `asset(kind=script)` 场次切片 | ←章节；→分镜；refs 资源 |
| 角色设计 | `prompt`/`image` | `character` | `FilmCharacter` + `FilmReference[]` | ←剧本(refs)；→图卡/分镜 |
| 场景/道具/特效设计 | `prompt`/`image` | `scene`/`prop`/`effect` | film asset + refs | 同上 |
| 运镜/画面/动作风格预设 | `prompt` | `camera`/`frame`/`action` | 选中的提示词积木组合 | →分镜（refs） |
| 设定图卡 | `image` | `design_card` | `FilmReference`（图+描述词） | ←资源；→关键帧 |
| 分镜 | `text`/`group` | `shot` | `ShotSpec`/`ShotSegment` + in/out 秒 | ←剧本+资源+风格；→关键帧/视频 |
| 关键帧 | `image` | `keyframe` | image asset + 帧位 | ←分镜+图卡；→视频 |
| 视频片段 | `video` | `clip` | video asset + 时长/分镜引用 | ←关键帧+分镜；→成片 |

## 7. 核心交互：右键 / 浮动工具条「一键编排」

操作范式：**选中节点 → 右键（或浮动工具条）→ 一键让 agent 据上游已确认内容生成下游节点并自动连线**。
菜单只展示该节点**当前可执行的下一步**（能力感知）：

| 在此节点右键 | 一键菜单项 | 产出 |
|--------------|-----------|------|
| 章节文本节点 | 转剧本 | 场次剧本节点 + 抽取/合并项目级实体资源 |
| 剧本节点 | 补抽资源、生成分镜 | 角色/场景/道具/特效节点；分镜节点 |
| 角色设计节点 | **生成角色图**（多面向多选） | 三视图/表情/远近/服装/五官/武器道具 图卡 |
| 场景/道具节点 | 生成概念图 | 设定图卡 |
| 分镜节点 | 生成关键帧、生成视频 | 关键帧节点 / 视频片段节点 |
| 关键帧节点 | 出视频（首尾帧 I2V） | 视频片段节点 |

统一规则：① 一键先弹**可编辑的提示词预览**（内置模板已填好，人可改了再发起）；② 产物排到下一泳道并连血缘边；
③ 全程「人能改、agent 能续」（§9）。

## 8. 各阶段详细设计

### S0 立项与视觉总设定（Style Bible，项目级）

- 新建影视项目时选：**类型**（电影/剧集/短剧/动画/广告）、**视觉媒介**（2D/3D/写实/动漫/自定义）、
  **画幅比例**、**节奏基线**（平均镜时，如 3s/镜）、**整体色彩/美术风格**、**统一/反向提示词**。
- 落 `project.metadata.film.series` + 一个 `style_bible` 节点；**所有下游生成自动继承**（拼进 prompt）。
- 人/agent 可随时微调；改动通过 §9 过期机制提示「全片视觉设定已变更」。

### S1 文稿工作台（大文本导入 · 分章 · 分片 · 编辑）—— 画布之外

1. **导入**：`.txt/.md/.docx`、粘贴；大文件**分片流式导入**（避免一次性入内存/渲染卡顿）。
2. **自动分章**：规则优先（`第N章/Chapter N/卷/序章/番外` 正则）；规则不命中时 agent 语义切分并给章标题/摘要，人确认边界。
3. **手动编章**：新增/合并/拆分/重排，逐章 Markdown 编辑。
4. **落库**：每章 `asset(kind=chapter)`（原文 + 章号/摘要/状态）；整部文稿 `asset(kind=manuscript)` 仅存分章索引，
   **不内联全文进画布快照**。
5. **入画布**：把某章「拉入画布」→ 生成轻量**章节文本节点**（引用 chapter asset）。

### S2 章节 → 剧本（右键一键，输出「剧本内容 + 抽取实体资源」）

- 章节节点右键「转剧本」：agent 读原文 + 继承 S0 风格，**一键产出**：
  1. **场次剧本节点**：场号、内/外景、时间、地点、人物、动作、对白、旁白；落 `asset(kind=script)`，按场切多个节点；
     与章节连 `derived_from`。
  2. **触发 S3 实体抽取**：识别本章出场的角色/场景/道具/特效，增量合并到**项目级**库（见 S3）。
- **人编辑**剧本文本；**agent 续作**单场润色/扩写/精简/改风格（`text_rewrite`）。
- 升级点：把规则式 `handleBreakdownScriptAsset` 拆为「章→剧本 + 实体抽取」(本步) 与「剧本→分镜」(S6)，均可走 agent。

### S3 剧本 → 实体资源（项目级共享，一次抽取全实体）

- **一次解析产出全部实体**（修正原 P1 拆分）：角色（`FilmCharacter`）、场景（`FilmScene`）、道具/特效（film asset）。
- **项目级、跨章共享、增量合并**（修正 P9）：不隶属任何单章；后续章节再转剧本时**追加新实体/补全已有实体**，
  沿用 `existingByKindAndName` 去重，绝不重复建卡。画布以**引用节点**呈现，全局同步。
- **角色详细表**字段：外貌/发型/服饰/标志道具/性格/表情基准/声线/一致性锁定项/生命周期阶段。
- 剧本节点与所引用资源连 `references` 边（标明「这场用到这些角色/场景/道具」）。
- **协作点**：人补全/校正实体字段 → agent 据此进入 S4 出图。

### S4 资源 → 设定图卡（一致性锚点；角色多面向是标杆环节）

在资源节点右键「生成图」，弹**面向多选**，批量产出**设定图卡节点**，每面向一套**内置模板**（§10）自动填入资源字段：

| 角色面向 | 内置模板要点（character sheet 积木） |
|----------|--------------------------------------|
| **三视图** turnaround | `character turnaround, front/side/back, T-pose, consistent character, neutral bg, full body, model sheet` |
| **表情** expression sheet | `expression sheet, multiple expressions`（复用表演表情积木）`, same character, consistent face` |
| **远近** distance | `shot scale: extreme long/full/medium/close-up`（复用景别积木）`, same character` |
| **服装** costume | `costume sheet, multiple outfits, full body, same character`（绑定 `costume` + 阶段服装） |
| **五官** facial features | `facial feature close-up, eyes/nose/mouth/hairline, front + 3/4 view, beauty lighting` |
| **武器/道具** weapon & props | `prop sheet, signature weapon/item`（绑定 `signatureProps`）`, multiple angles, isolated bg` |

机制：
- **基准图 + 一致性**：先出**三视图正面**为「角色基准图」（`FilmReference.kind='concept'`）；其余面向走 `image_to_image`
  喂基准图，保同一张脸/同一设定。
- **场景/道具同理**：出概念图/多角度设定图，作为后续关键帧的视觉锚点。
- **批量排布**：多选 → 批量任务 → 产物归该资源「图卡组」泳道，回挂为对应 `kind` 的 `FilmReference`。
- **提示词组装**：`资源字段` + `面向模板积木` + `S0 视觉总设定` + `项目统一/反向提示词` →最终 prompt（人可改后再发）。
- **协作点**：人挑/淘汰/标基准/补描述；agent 据被选基准续出衍生面向。

### S5 镜头/画面/动作风格预设（项目级，可复用）

- 从 §10 提示词积木库，agent 按 S0 风格**推荐**运镜/画面/动作组合，人确认后固化为**风格预设节点**（项目级）。
- 这些预设**不是从文本抽取的实体**（修正 P1），是创作决策；在 S6 分镜里被引用（`cameraPromptItemIds` 等）。
- 可随时新增/另存模板，跨章复用，保证全片镜头语言统一。

### S6 剧本 + 资源 + 风格 → 分镜（按秒切分）

- 选中「场次剧本 + 相关资源/图卡 + 风格预设」→ 右键「生成分镜」：agent 拆成**分镜序列**，每镜 = `ShotSpec`/`ShotSegment`：
  - **时间**：`inSec/outSec/durationSec`。**按秒切分依据**（修正 P6）= 对白朗读时长（按语速估）+ 动作节拍 + S0 节奏基线；人可微调。
  - **镜头语言**：景别/角度/运镜/构图/焦段（引用 S5 运镜预设）。
  - **主体**：角色（引用资源）+ 动作（动作预设）+ 表情/情绪/服饰/道具。
  - **环境**：地点/时间/天气/光线/氛围（引用场景资源）。**画面**：构图/光影/色彩/风格（引用画面预设）。
  - **对白/旁白**。
- 承载于 `ShotGroup → ShotSegment`（已存在），片段升级字段：`inSec/outSec/durationSec/keyframeNodeIds/cameraDesignId/actionDesignId/frameDesignId`。
- **协作点**：分镜表单 + 时间轴双视图；人增删镜/改时长/改镜头语言/调引用；agent「重切这场」「拆成两镜」「补反打」。

### S7 分镜 → 关键帧（消费设定图卡，首尾帧衔接）

- 每个分镜右键「出关键帧」：据镜头语言 + 引用的角色/场景**设定图卡**，出 **首帧 / 尾帧 /（可选）中间帧**
  （`text_to_image`，或以角色基准图/场景图 `image_to_image` 保一致）。
- 关键帧带**帧位**（`first/last/mid/@t=Ns`）+ 分镜引用。
- **首尾帧衔接规则**（修正 P5）：默认**上一镜尾帧 = 下一镜首帧**的候选，保证镜间连续；人可断开。
- **协作点**：换帧/重生成/锁帧；这些帧是 S8 视频的视觉锚点。

### S8 关键帧 + 分镜 → 逐段视频（I2V）

- 每个分镜右键「出视频」：**首帧（+尾帧）关键帧 + 分镜提示词（镜头语言/动作/对白节奏）+ 时长** 喂视频模型，逐段产 `clip`：
  - 有首尾帧 → `image_to_video`/视频编辑（首尾插值，需 manifest `maxImages>=2`）。
  - 仅一帧 → 单图 I2V；多参考图先 `image_compose` 合一张再 I2V（沿用既有面板策略）。
  - 无关键帧 → `text_to_video` 兜底。
- **逐段** = 一镜一段；段间一致性靠共享角色基准图 + 首尾帧衔接。
- **协作点**：单段重跑/换模型/调时长运镜后重生成；agent「更慢」「补转场」。

### S9 后期与成片（修正 P8）

- 分镜区→视频区全部生成后，「按分镜顺序拼接」导出（本期：顺序拼接 + 转场占位）。
- 后续：配音（对白 TTS，时长可反哺 S6 切分）、字幕、配乐、调色。开放问题见 §14。

## 9. 贯穿性机制：一致性 + 人机协作 / 过期契约

### 9.1 一致性（全片成败关键，修正 P5）

- **风格一致**：S0 视觉总设定被所有生成继承（拼 prompt）。
- **角色一致**：三视图正面为基准图，衍生图卡/关键帧走 I2I 喂基准 + `lockedAttributes` 锁定项；
  后续可接角色 LoRA/参考一致性模型（manifest 能力决定，§14）。
- **场景一致**：场景概念图为锚点，同场景镜头复用。
- **镜间一致**：首尾帧衔接（S7）。

### 9.2 人机协作 / 过期契约（每阶段统一状态机）

```text
empty → drafting(agent) → draft → editing(human) → confirmed → (上游变) stale → 重生成/手动确认
```

- **闸门**：下游正式生成**默认只读上游 `confirmed`** 内容（保证「agent 基于人已确认结果生成」）。
- **过期传播**：上游 confirmed 变更 → 沿 `used_as_input`/`generated`/`references` 边把下游标 `stale`（待更新角标），
  可「仅标记」或「级联重算」。
- **版本而非覆盖**：agent 重生成产**新版本**（复用「复制任务为分支/换模型重跑」）；人改 agent 产物则原地 `ai_edited`。
- **双向**：人编辑后有「据此生成下游」按钮；agent 产物即可进入人工编辑态（结构化字段/文本可改）。
- 仅在节点 `data` 加少量字段：`productionState/editedByHuman/confirmedAt/version/staleFrom`，不动数据库表。

## 10. 内置提示词模板库（全流程引擎，必须做厚）

「内置提示词非常重要」落在这里。统一「**积木 + 命名模板**」两层，扩展既有库：

- **积木层**（结构化英文短语 + 中文 label，沿用 `promptFragment` 形态）：
  - 既有：`canvasFilmPrompts`（景别/角度/运镜/构图/焦段/光影/色彩/风格/反向…）、`canvasFilmPerformancePrompts`（表情/动作/情绪）。
  - 新增 `canvasCharacterSheetPrompts`（三视图/表情九宫格/景别变体/服装/五官/武器道具/模型表风格/打光/背景）。
- **模板层**：把一组积木 + 槽位（`{appearance}/{costume}/{props}/{style}/{scene}`）固化成一键预设；每个 S4 面向 ≥1 默认模板。
- **统一供给**：S4 资源出图、S7 关键帧、S6 分镜 prompt 均从同一库取词，保证全片视觉语言一致。
- **可沉淀**：用户/agent 任意组合「另存为模板」（复用既有「保存为镜头预设」机制），项目级积累。

## 11. 数据结构扩展（最小增量，不新建表）

1. **`FilmAssetKind` 新增** `manuscript`/`chapter`。实体资源（角色/场景/道具/特效）与风格预设均**项目级**
   （`project.metadata.film.*`），跨章共享。
2. **新增内置** `canvasCharacterSheetPrompts`，与现有 prompt 库同构。
3. **`ShotSegment` 扩展**：`inSec/outSec/durationSec/keyframeNodeIds/cameraDesignId/actionDesignId/frameDesignId`。
4. **`CanvasNodeData` 扩展**：`pipelineRole`、`productionState`、`editedByHuman`、`confirmedAt`、`version`、`staleFrom[]`。
5. **`CanvasFilmProjectMetadata` 扩展**：`manuscript{ sourceAssetId, chapters[] }`、`stylePresets{ camera/frame/action }`、
   `styleBible`（继承用全局风格）。
6. **`FilmEpisode ↔ chapter ↔ board`** 三者映射（默认一章一集一 board，可 N 章合 1 集，见 §14）。

## 12. Agent 能力与编排

每步本质是「带上下文 + 工具权限的一次 agent/模型调用」（与多媒体方案 §11.3 一致）。建议 agent 动作（经画布 task/MCP 暴露）：

- `manuscript.split_chapters`（语义分章兜底）
- `chapter.to_screenplay`（章→场次剧本 + 触发实体抽取）
- `screenplay.extract_entities`（剧本→角色/场景/道具/特效，增量合并）
- `style.recommend_presets`（按视觉总设定推荐运镜/画面/动作预设）
- `resource.to_design_cards`（资源→多面向设定图卡）
- `screenplay.to_shots`（剧本+资源+风格→按秒分镜）
- `shot.to_keyframes`（分镜→关键帧，含首尾帧衔接）
- `shot.to_clip`（分镜+关键帧→逐段视频）

编排执行：单节点运行 / 从某节点向后 / 整章全流程 / 失败从失败节点续跑；只读上游 `confirmed`，产物回写节点 + 血缘 + `productionState`。

## 13. 分期落地

- **P0 文稿工作台**：分片导入、规则分章、手动编章、章落 `asset(kind=chapter)`、画布章节节点。
- **P1 主线最短闭环**：S0 视觉总设定 → 章→剧本 → 剧本→分镜（先复用 ShotGroup）→ 分镜→视频，跑通端到端。
- **P2 实体资源 + 角色图卡（标杆）**：S3 项目级实体抽取/增量合并；S4 角色多面向图（三视图/表情/远近/服装/五官/武器道具）+
  `canvasCharacterSheetPrompts` + 角色一致性（基准图 + I2I）。
- **P3 细粒度分镜 + 关键帧**：按秒切分、关键帧（首/尾/中）、首尾帧衔接、首尾帧 I2V 逐段。
- **P4 协作契约**：生产状态机、confirm/lock、过期传播与级联重算、版本化。
- **P5 风格预设 + 编排 + 成片**：S5 风格预设复用、DAG 全流程运行/失败续跑、S9 按分镜拼接导出。

每期都保持「人能编辑 + agent 能据人结果续生成」的双向性。

## 14. 开放问题（需产品确认）

1. **章/集映射**：默认「一章一集一 board」还是允许「多章合一集」？（影响 board↔episode 建模）
2. **文稿工作台位置**：画布内右侧抽屉 vs 与画布平级的独立顶级视图？（倾向独立视图 + 画布引用节点）
3. **按秒分镜切分依据权重**：对白时长 / 动作节拍 / 节奏基线三者如何加权？是否允许「锁定总时长反推」？
4. **成片范围**：本期是否含配音/字幕/配乐/调色，还是只做画面顺序拼接 + 转场占位？
5. **一致性策略上限**：角色一致性止于「基准图 + I2I」，还是接 LoRA / 参考一致性模型？（取决于 manifest 能力）
6. **风格预设来源**：完全 agent 推荐，还是预置若干「类型片风格包」（武侠/悬疑/都市…）供一键套用？
