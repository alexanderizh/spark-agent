# 无限画布「剧本到视频片段」完整测试用例

> 状态: 实施中 | 最后核对: 2026-06-21

本文覆盖当前无限画布从「文稿导入 → 分章 → 章转剧本 → 剧本拆解 → 资源/图卡 → 按秒分镜 → 关键帧 → 视频片段 → 成片清单」的已落地能力，并包含「制作面板 / Production Cockpit」和「分镜导演台」专项测试。

## 1. 测试范围

### 1.1 覆盖模块

- 文稿与章节：导入 `.txt/.md`、UTF-8/GBK 解码、标题分章、长度分片、关闭分章按单章导入、范围导入、章节阅读、章节删除、整本文稿级联删除。
- 视觉总设定：Style Bible 保存、重置、下游 prompt 继承。
- 章节转剧本：创建剧本资产、发起 `text_rewrite` 任务、空正文保护。
- 剧本拆解：规则式抽取角色/场景/显式道具、去重合并、创建分镜分组与片段。
- 项目资产中心：剧本/角色/场景/道具/特效/提示词库的创建、编辑、筛选、排序、插入画布、引用统计、删除保护。
- 角色/概念图：角色多面向出图、基准图存在时非基准面向走 `image_to_image`、场景/道具/特效概念图。
- 风格预设：运镜/画面/动作预设保存、展示、应用到分镜片段。
- 分镜：手动创建/编辑/删除分镜分组与片段、按剧本自动分镜、时长字段、引用角色/场景、展开到画布。
- 关键帧：生成首帧/尾帧、将画布选中图片设为关键帧、关键帧节点回链分镜。
- 视频片段：有关键帧/设定图时走 `image_to_video`，无锚点时退化 `text_to_video`，prompt 继承分镜与 Style Bible。
- 成片清单：时间线排序、时长累计、EDL Markdown 预览与插入画布。
- 制作面板：六阶段完成度、下一步建议、深链到资产中心对应 tab。
- 流水线节点：`pipelineRole` 自动标记、右键/节点头部下一步动作、生产状态 `confirmed/stale`、下游过期传播。
- 分镜导演台：多镜头管理、主体/物件/相机/关键帧编排、2.5D/3D 预演、构图健康度、快捷重排、保存草稿、插入提示词、生成截图与提示词节点。

### 1.2 不覆盖或仅冒烟

- 后端真实 ffmpeg 拼接、配音、字幕、配乐、调色：当前未落地，仅验证 EDL 和顺序清单。
- LLM 结构化抽取资产：当前仍以规则式拆解为确定性基线，仅验证文本模型任务能发起。
- 第三方媒体模型生成质量：只验证任务参数、输入锚点、状态流转和输出节点，不以视觉质量作为自动化通过条件。

## 2. 基础测试数据

### 2.1 文稿样例

```text
序章
雨夜，旧车站的灯忽明忽暗。林岚握着一枚铜钥匙，听见广播里传来自己的名字。

第一章 风起
林岚推开候车室的门。
陈默：你终于来了。
角落里，一只黑色手提箱发出轻微震动。

第二章 追逐
林岚和陈默穿过月台，身后传来急促脚步声。
陈默：别回头，往三号站台跑。
道具：铜钥匙、黑色手提箱
```

### 2.2 剧本样例

```text
场次 1 内景 候车室 夜
角色：林岚、陈默
场景：旧车站候车室
道具：铜钥匙、黑色手提箱
动作：林岚推门进入，陈默从阴影里转身。
林岚：你是谁？
陈默：现在没时间解释。
```

### 2.3 媒体节点样例

- 图片节点 A：`type=image`，有 `assetId`、`data.url`，标题为「林岚定妆」。
- 图片节点 B：`type=image`，有 `assetId`、`data.url`，标题为「候车室概念图」。
- 分镜片段 S1：引用角色「林岚」、场景「旧车站候车室」，`durationSec=4`。
