# 无限画布折叠编组追加优化设计

> 状态: 待开发 | 最后核对: 2026-08-01

## 目标

为展开编组增加明确的头部折叠入口，将折叠文件夹展示高度增加 60px，并保证折叠文件夹标题在点击画布其他区域后保存并退出编辑态。

## 交互设计

- 展开组的头部右侧状态区新增圆形折叠按钮，采用向上收起图标，`aria-label` 为“折叠编组”。
- 折叠按钮只在展开的组节点显示；点击后写入 `data.collapsed: true`，并阻止点击和双击冒泡，避免触发节点编辑或其他画布动作。
- 右键菜单和双击组节点的原有折叠能力保持不变。
- 折叠文件夹标题仍通过双击进入编辑；按 Enter 或原生失焦保存，按 Escape 取消。
- 编辑期间捕获文档级 `pointerdown`。当指针目标位于编辑器之外时立即提交，因此即使 React Flow 阻止画布默认聚焦行为，也能保存并退出编辑态。
- 点击输入框内部不提交；提交中的重复 blur / pointerdown / Enter 继续复用现有去重逻辑。

## 视觉设计

- 折叠投影由 `420×300` 调整为 `420×360`。
- 顶部两张插页、插槽曲线和图标保持现有纵向位置，不整体拉伸，新增的 60px 全部用于延长文件夹下半部分。
- 节点数量、标题和颜色按钮继续贴近文件夹底部，使下半部分留白更舒展。
- 展开组头部按钮放在右侧，尺寸跟随当前主题 meta bar 高度，在默认、UIUX V4 与 cinematic 主题中保持可点击和清晰可见。

## 数据与布局安全

- 折叠高度只属于 React Flow 展示投影，真实组节点的 `width`、`height` 不变。
- 展开继续恢复原组宽高和全部子节点状态。
- 新按钮只调用现有 `updateNodeData`，不增加新的持久化字段。

## 测试

- 纯函数测试断言折叠投影尺寸为 `420×360`。
- 组件/集成测试断言展开组头部存在折叠按钮，点击仅写入 `collapsed: true`。
- 标题编辑器测试模拟画布阻止默认聚焦的场景：向 `document.body` 派发捕获阶段 `pointerdown`，断言保存并退出编辑态。
- 回归运行布局持久化、折叠投影、标题编辑器、折叠组件、事件路由、类型检查和 Desktop 构建。

## 非目标

- 不增加展开按钮或新的文件夹动画。
- 不改变组成员关系、子节点坐标或组的真实尺寸。
- 不修改任意颜色选择器、预览图片排序或折叠快捷键。
