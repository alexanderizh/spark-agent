# 无限画布节点 UI/UX V2 设计方案

> 状态: 已废弃 | 最后核对: 2026-07-13

本稿已由更完整的 [无限画布产品 UI/UX V3 设计规范](./2026-07-13-canvas-product-uiux-v3-design.md) 取代。

## 1. 目标

这次改造不是单纯“把卡片画漂亮”，而是重新建立节点在创作过程中的信息层级、尺寸系统、运行反馈和空间秩序。重点解决：节点状态不易读、运行过程缺少反馈、空节点不可行动、多产物浏览割裂、长内容节点尺寸不足，以及所有添加入口缺少统一防重叠布局。

高保真原型：[`docs/design-prototypes/canvas-node-uiux-v2.html`](../../design-prototypes/canvas-node-uiux-v2.html)

## 2. 设计方向

探索过三种方向：

1. **轻量白板**：弱边框、浅背景，容易亲近，但复杂影视项目里状态和血缘会快速失焦。
2. **数据流控制台**：状态与端口非常清楚，但容易变成工程工具，内容本身退居次位。
3. **创作剪辑台（采用）**：深色低干扰画布、内容优先、电影制作式状态语言，类型色只承担导航与状态，不把节点染成彩色卡片。

## 3. 节点结构

每个节点统一为四层：

- **连接层**：端口、连线、选中轮廓、缩放锚点。
- **控制层**：36–40px 标题栏，承载类型、标题、版本、状态、主操作。
- **内容层**：素材预览、文本、表格、波形或任务阶段。
- **反馈层**：进度、错误修复、空态行动、多产物摘要、运行历史。

标题栏不再堆多个同权徽标。默认只保留一个主状态；类型、角色、产物等信息通过图标、窄类型色和次级文本表达。

## 4. 尺寸系统

| 规格 | 默认尺寸 | 适用节点 | 规则 |
| --- | ---: | --- | --- |
| S | 320×180 | 空节点、音频、简单 Prompt | 快速扫读，内容最多 3 行 |
| M | 360×280 | 普通任务、图片、短文本 | 常用基础规格 |
| L | 560×360 | 视频、任务多产物预览、设定卡 | 内容主导 |
| Document | 680×520 | 长文稿、剧本 | 稳定阅读宽度，内部滚动 |
| Storyboard | 980×620 | 分镜脚本表 | 表格视图，不退化为便签 |
| Group | 内容驱动 | 多产物、手动组 | 网格测量后由内容反推外框 |

节点允许用户缩放，但“恢复推荐尺寸”作为标准动作。任务运行时节点不因产物比例改变外框，避免画布跳动；完成后只更新内容区域，展开产物进入独立组。

## 5. 状态与动效

### 5.1 任务状态

- **待提交**：中性边框，内容区展示必要输入与运行按钮。
- **排队中**：状态点呼吸，显示队列位次；不使用无限旋转器。
- **运行中**：1px 低亮度周向光束、阶段进度、当前产物序号、已耗时；预览区可显示扫描带。
- **已完成**：周向动效在 280ms 内收束为完成闪光，保留 100% 进度 1.2 秒后淡出。
- **失败**：静态错误色，不做持续抖动；展示可理解原因和“修复后重试”。
- **取消**：降低内容饱和度，保留重新运行入口。

所有持续动效遵守 `prefers-reduced-motion`，不可成为读取状态的唯一手段。

### 5.2 节点进入画布

- 单节点：从目标落点缩放 `0.96 → 1`、透明度 `0 → 1`，180ms。
- 批量节点：按空间顺序错峰 35ms，总时长不超过 420ms。
- 自动整理：节点使用位置插值，连线同步；移动超过一个视口时先缩放到全局再回焦。
- 产物展开：组框先出现，子节点从任务节点方向沿连线展开，不用随机散射。

## 6. 多产物任务

任务节点内部仍保留“本次运行产物摘要”：缩略图条、产物数量、主产物和运行历史。完成后按以下规则自动物化：

1. 产物数为 1：在任务右侧创建单一产物节点。
2. 产物数为 2–9：创建“任务产物组”，产物按接近方形的均匀网格展开。
3. 产物数超过 9：首屏展示 3×3，组内出现分页/虚拟化入口，避免创建巨型画布区域。
4. 一个产物可标为“主产物”；下游默认连接主产物，用户可切换到候选或整个集合。
5. 组可收起为 250×44 的摘要条，收起不删除产物节点或血缘关系。
6. 再次运行生成新的 Run 分区，不覆盖旧产物；默认展开最新 Run，历史 Run 折叠。

## 7. 统一放置引擎

所有入口必须只调用一个 `placement transaction`，输入来源不同但算法一致：

- 手动工具栏 / 右键菜单；
- 拖入文件、资产、历史、模板；
- 任务节点自动创建与任务完成产物；
- Agent/MCP 自动添加；
- 多产物展开、分镜展开、组展开；
- 复制、粘贴、重复节点。

放置事务按以下顺序执行：

1. **确定意图锚点**：鼠标点、选区右侧、来源节点右侧或视口安全中心。
2. **计算批次包围盒**：先按最终节点尺寸完成本地布局，再整体找位置，禁止逐个节点各自找空位。
3. **建立障碍集合**：现有节点、展开组边界、锁定区域、浮动面板遮挡区均计入；增加 48–72px 安全间距。
4. **候选搜索**：优先右侧，其次下方；沿扩展方形/螺旋环寻找第一个无碰撞候选，不在原点反复偏移。
5. **视口约束**：新内容至少 35% 位于当前可视区域；超出时只平移视口，不擅自缩放用户画布。
6. **原子提交**：批次位置与组外框一次写入；失败时全部回滚，避免半批次叠放。
7. **并发占位**：进行中的自动任务预留其预计产物包围盒，避免两个几乎同时完成的任务落到同一位置。

## 8. 空态

空态必须说明“它在等什么”和“下一步能做什么”：

- 空文本：输入文字 / 粘贴 / 连接上游。
- 空媒体：上传 / 从资产中心选择 / 连接生成任务。
- 空任务：补齐缺失输入或模型参数，直接聚焦到对应编辑区。
- 空组：拖入节点或解散组；组内给出明确投放热区。
- 失效引用：显示来源已删除，并提供重新绑定而不是只显示占位图。

## 9. 实施边界

第一阶段先落统一节点框架、尺寸 token、状态视觉和设计稿中覆盖的典型节点；第二阶段接入统一放置事务与多产物组；第三阶段迁移特殊节点（3D 导演台、视频工作台）并做性能与无障碍验收。

`CanvasWorkspaceView.less` 已超过 13,000 行，后续实现不得继续向该文件堆叠节点 V2 样式。新样式拆到独立模块，并逐步迁移旧节点样式。
