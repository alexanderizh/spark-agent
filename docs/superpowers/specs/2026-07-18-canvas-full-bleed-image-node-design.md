# Canvas 全幅图片节点设计

> 状态: 已落地 | 最后核对: 2026-07-18

## 目标

有有效图片内容的图片节点以图片自身宽高比作为整个节点的宽高比，节点信息与操作以覆盖层展示，避免固定头尾栏参与比例缩放后产生底部空隙。

## 适用范围

- 仅适用于 `type === 'image'` 且存在有效 `data.url` 的图片资产节点，包括上传图片与已经物化为图片节点的生成产物。
- 空图片占位节点、文本、音频、视频、分组、AI 操作节点及操作节点内部的图片预览保持原有卡片布局。
- 有关联资产且资产记录包含原始宽高时，已有图片节点按原始比例修正展示尺寸；缺失尺寸元数据时保留节点当前尺寸。

## 展示结构

- 图片铺满整个节点，节点外框不再为 meta、标题或快捷操作预留额外高度。
- 原有顶部 meta 条改为覆盖在图片顶部的半透明层。
- 原有标题栏与快捷底栏合并为一条底部半透明层：左侧显示标题与状态，右侧保留编辑入口。
- 提取子视图按钮上移到合并底栏之上，避免点击区域重叠。
- 连线锚点、选中边框、缩放手柄与右键菜单行为保持不变。

## 尺寸规则

- 已知原始尺寸时：`renderedHeight = round(renderedWidth * imageHeight / imageWidth)`。
- 新建普通图片节点和批量导入图片节点返回图片正文尺寸，不再加入 meta 高度。
- 缩放保持整个节点比例；因为节点比例已经等于图片比例，固定浮层不会再被计入尺寸。
- 资产尺寸未知时不猜测比例，继续使用当前节点尺寸。

## 验证

- 尺寸单测覆盖横图、超宽图、竖图与批量导入。
- chrome 单测覆盖有图图片节点为零额外高度、空图片节点仍使用旧高度。
- 展示尺寸单测覆盖资产尺寸纠正与缺失尺寸回退。
- UI 集成测试覆盖专用 class、合并浮层以及 V4 浮层样式。
- 运行相关 Vitest、桌面端类型检查，并对目标文件执行 ESLint。
