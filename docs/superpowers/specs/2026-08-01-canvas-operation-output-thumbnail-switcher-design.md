# Canvas 多产物节点缩略图切换器设计

> 状态: 实施中 | 最后核对: 2026-08-01

## 目标

当操作节点聚合了多个历史图片产物且节点处于选中状态时，在节点下方显示单行缩略图切换器。用户可以不打开任务面板，直接跨历史运行浏览并切换节点主预览产物。

## 范围

- 仅适用于操作节点。
- 聚合该节点全部历史运行中的可预览图片产物，至少存在 2 个图片产物时才显示。
- 非图片产物不进入缩略图条；文本、音频、视频及集合模式的现有预览行为不在本次改造范围内。
- 切换器只在节点处于 React Flow 选中状态时显示；多选中的节点同样按各自选中状态显示。
- 不修改任务、运行或产物的持久化数据结构。

## 交互与排序

- 缩略图按运行从新到旧排列；同一次运行内沿用产物原始顺序。
- 点击缩略图后，节点主预览切换到该产物，同时切换到它所属的历史运行。
- 点击继续复用现有 `primaryOutputId` 与 `primaryOutputSelection: 'manual'` 写回逻辑，使任务面板、节点预览及后续引用保持一致。
- 当前产物使用圆角高亮底座，并在选择变化时自动滚入可见区域。
- 节点失去选中状态后切换器隐藏；再次选中时依据当前主产物恢复运行位置和高亮。
- 保留现有运行历史左右切换按钮；移除节点内部的产物圆点，避免两套同义的产物切换入口。

## 布局与视觉

- 切换器作为节点壳层内、节点卡片外的浮动附属组件渲染，定位在卡片下方约 12px。
- 宽度约为节点的 80%，在节点下方水平居中；不计入节点持久化尺寸、碰撞尺寸或自动布局。
- 使用单行横向滚动，禁止换行并隐藏原生滚动条；触控板和滚轮均可浏览超出内容。
- 缩略图使用固定尺寸与 `object-fit: cover`，容器使用大圆角、轻边框和画布主题表面色。
- 图片加载失败时在原位置显示图片占位图，不影响其他产物切换。
- 组件使用 `nodrag nopan nowheel` 交互隔离，点击和滚动不会拖动节点或缩放画布。

## 组件与状态边界

### `OperationOutputDeck`

将当前运行索引和产物索引改为受控状态。它继续负责主预览、运行历史按钮及运行状态展示，但不再单独拥有产物选择状态。

### `OperationOutputThumbnailSwitcher`

新增独立、聚焦职责的缩略图组件，输入全部运行、当前产物 ID 和选择回调。组件负责扁平化图片产物、渲染滚动列表、活动态与自动滚入可见区域，不直接写入节点数据。

### `CanvasNode`

作为状态协调层，持有当前运行与产物索引，并把同一个选择动作传给主预览和缩略图切换器。选择动作统一更新本地预览状态及节点的默认产物字段。

## 数据流

1. `CanvasNode` 接收已有的 `operationRuns` 和 `resolveCanvasOperationOutputState` 结果。
2. 初次渲染或默认产物变化时，将本地运行/产物索引同步到解析结果。
3. 缩略图组件按运行顺序构建 `{ runIndex, outputIndex, output }` 列表并过滤非图片产物。
4. 用户点击缩略图后，组件回传目标坐标与产物。
5. `CanvasNode` 更新受控索引，并通过 `actions.updateNodeData` 写回主产物选择。
6. `OperationOutputDeck` 使用新索引刷新主预览和运行序号。

## 异常与边界处理

- 历史运行为空、图片少于 2 个或节点未选中：不渲染切换器。
- 当前主产物不是图片：缩略图条仍可展示，但初始没有图片活动项；点击图片后进入正常活动态。
- 运行或产物在异步刷新中被删除：索引重新按解析出的默认产物收敛，不保留悬空位置。
- 缩略图资源加载失败：显示占位状态并保留可点击能力。
- 缩略图很多时只横向滚动，不扩展节点高度或创建第二行。

## 测试与验证

- 纯模型测试覆盖跨历史运行的图片聚合、排序、非图片过滤和不足 2 项时隐藏。
- React 测试覆盖仅选中时显示、点击跨运行切换、主产物写回、活动项及加载失败占位。
- 源码或样式集成测试覆盖节点外定位、80% 居中宽度、单行横向滚动和交互隔离 class。
- 回归测试覆盖现有运行历史按钮仍可工作、单产物节点无额外 UI、未选中节点不隔离画布滚轮。
- 运行相关 Vitest、桌面端类型检查、目标文件 ESLint、`git diff --check`，并执行 GitNexus 变更检测和索引更新。
