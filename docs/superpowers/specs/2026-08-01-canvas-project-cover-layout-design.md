# 无限画布项目封面完整预览布局设计

> 状态: 已落地 | 最后核对: 2026-08-09

## 背景与目标

无限画布项目详情页当前使用固定 `240px` 高横幅和 `object-fit: cover` 展示项目封面。该方式能铺满容器，但角色设定板、分镜板、长图和竖图会被裁切，用户无法在基础信息页判断封面的完整内容。

本次调整采用“完整图 + 氛围背景”方案：详情页高度保持稳定，前景封面始终完整可见，空余区域由同图生成的弱化背景填充；点击封面进入完整预览。方案只调整项目详情页，不改变项目卡片、侧栏缩略图、封面文件存储或 IPC 协议。

## 页面布局

- 详情页封面容器在常规桌面宽度保持 `240px` 高，视口宽度不超过 `720px` 时降至 `180px`，不根据原图比例无限撑高页面。
- 容器底层使用同一封面图以 `cover` 铺满，并增加模糊、缩放和暗色蒙层，只承担氛围填充作用。
- 容器上层使用同一封面图以 `contain` 居中展示，保证任何宽高比都完整可见。
- 上层图片不得额外添加白边或固定背景色；图片自身的透明区域由底层氛围背景承接。
- 封面加载失败时显示现有空封面状态，不保留破损图片或不可操作的预览入口。

## 交互

- 点击已有封面的主体区域只打开完整预览，不再触发文件选择器。
- 悬停封面时显示轻量底部渐变和“查看大图”“更换封面”操作；不使用覆盖整张图片的深色遮罩。
- “更换封面”是独立按钮，点击后打开现有图片文件选择器，并阻止事件冒泡到完整预览。
- 没有封面时，点击空状态仍打开图片文件选择器，保持当前首次上传路径。
- 置顶与更多项目操作从封面右上角移到标题操作区，与“打开画布”同层，避免遮挡封面内容。
- 完整预览沿用项目资源预览的视觉语言，以遮罩层展示原始封面；支持点击关闭按钮、点击遮罩和按 `Escape` 退出。
- 首次交付不增加图片编辑、焦点裁切、下载、旋转或独立缩放控件；预览图按视口 `contain` 展示，浏览器窗口变化时自适应。

## 组件边界

- `CanvasProjectDetail.tsx` 负责封面默认态、悬停操作、文件输入和预览开关状态。
- `cinematic/project-surface.less` 负责双层封面、响应式高度、悬停态和预览层样式，并由 `cinematic/projects.less` 统一装配。
- 封面 URL、上传写入与清除流程继续复用现有 `onUploadCover` 和 Canvas API，不新增数据字段。
- 现有项目资源图片预览与封面预览保持各自状态，不改变资源列表的上一张/下一张逻辑。

## 无障碍与状态处理

- 有封面的主体预览入口使用可聚焦按钮语义，并提供“查看项目封面”标签；支持 `Enter` 和空格打开。
- 更换封面、置顶、更多操作均保留独立可读标签和焦点样式。
- 预览打开后焦点进入关闭按钮，关闭后返回封面入口；`Escape` 只关闭当前最上层预览。
- 用户启用减少动态效果时，取消背景与操作按钮的过渡动画。
- 背景装饰图使用空替代文本并禁止交互，前景图保留项目标题作为替代文本。

## 测试与验收

- 横图、竖图、超长图和接近方形图片在封面区域中均完整可见。
- 前景 `contain` 图和背景氛围层使用同一 URL，背景不会改变布局尺寸或抢占交互。
- 有封面时点击主体打开预览，点击“更换封面”只打开文件选择器；无封面时点击空状态仍可上传。
- 置顶、更多操作和“打开画布”行为保持不变，且不再覆盖封面内容。
- 预览可通过关闭按钮、遮罩和 `Escape` 关闭，图片加载失败时正确降级。
- 窄窗口下封面高度收敛，标题与操作区不溢出；减少动态效果偏好生效。
- 运行 Canvas 项目详情相关测试、Desktop 类型检查，并用 `git diff` 核对变更范围。

## 非目标

- 不为封面保存裁切坐标或焦点位置。
- 不修改项目列表卡片与侧栏缩略图的裁切策略。
- 不修改封面图片文件格式、压缩策略、存储位置或数据库结构。
- 不增加多封面、封面历史或自动从项目资源中选取封面的能力。
