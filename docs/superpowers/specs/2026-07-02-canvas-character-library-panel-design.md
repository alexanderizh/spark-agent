# 无限画布角色库面板设计

> 状态: 实施中 | 最后核对: 2026-07-02

## 背景

无限画布现有的影视资产中心已经支持角色资产、参考图与角色设定图生成，但缺少一个面向画布创作流程的“角色库”快捷面板。当前角色卡大多是一整张综合设定图，直接展示时信息密度高但不便复用，尤其不利于在画布、关键帧与后续图生图流程中快速选取“脸部特写 / 全身 / 三视图 / 表情条”等角色细节。

## 目标

- 在底部工具栏新增“角色库”入口，弹出一个独立于项目资产中心的新面板。
- 面板下半区展示当前项目内全部角色资产卡片，上半区展示当前选中角色的主视图与详情。
- 为角色卡新增“子视图”能力：通过新的角色裁切编辑器，在角色卡参考图上定义多个带类型和标题的裁切区域。
- 子视图首阶段以 metadata 形式保存为轻量子资产描述，不强制立即生成独立图片文件。
- 当用户把某个子视图“应用到画布”时，再即时裁出图片、上传为项目图片资产并插入到当前画布。

## 非目标

- 不复用现有图片标注弹窗的矢量绘制交互。
- 不做自动识别脸部 / 表情条 / 三视图。
- 不改造 3D 导演台内部数据结构与交互。
- 不引入新的数据库表，继续复用 `CanvasAsset.metadata`。

## 交互方案

### 1. 底部工具栏

- 在“项目资产中心”和“分镜导演台”之间新增“角色库”按钮。
- 点击后打开 `CanvasCharacterLibraryPanel`。
- 与其他底部浮层互斥打开，沿用 `closeCanvasFloatPanels` 的统一行为。

### 2. 角色库面板

- 结构分为上下两层：
  - 上半区：当前角色详情区，左侧为主预览图，右侧为角色名称、描述、标签、操作按钮。
  - 下半区：横向角色卡片带，仅展示当前项目内存在图片设定卡映射的角色，不展示纯文字角色卡。
- 主预览优先级：
  - 默认不选中任何子视图。
  - 若当前选中某个子视图，则展示单个子视图大预览。
  - 若存在子视图但当前未选中，则自动拼排展示全部子视图卡，作为角色总览视图。
  - 否则优先展示角色设定图卡（`design_card` 产物或其映射图片）。
  - 若没有设定图卡，再回退角色概念参考图（`references` 中首个可用图片）。
  - 若无图，退回空状态。
- 详情区动作：
  - `提取子视图`：打开新的角色裁切编辑器。
  - `应用至画布`：若当前选择了子视图，则应用子视图；否则应用整张角色参考图。
- 子视图条展示在主预览下方，支持切换、查看类型、删除与重新编辑。
- 画布中的图片设定卡节点右键菜单与悬浮工具栏都应提供 `提取子视图` 入口，直接打开同一编辑器。
- 角色库面板与子视图编辑器需要遵守统一浮层层级，编辑器必须始终位于角色库之上。
- 低高度窗口下，角色卡条不得与上方预览区重叠，应通过压缩卡片高度与固定底部条带高度解决。

### 3. 角色裁切编辑器

- 使用新组件 `CanvasCharacterSubviewEditor`，不复用现有标注器。
- 交互模型以“单次编辑一个子视图”为主：
  - 左侧图片舞台直接支持拖拽画框：用户在图片上按住拖拽即可创建一个新的子视图框。
  - 已创建的框支持拖动位置、拖拽四角微调大小。
  - 支持主图缩放，便于精细裁切。
  - 右侧表单与子视图列表。
  - 可创建、重命名、改类型、删除、重排子视图。
- 子视图类型首阶段支持：
  - `full_body`
  - `portrait`
  - `expression`
  - `turnaround`
  - `costume`
  - `prop`
  - `custom`

## 数据设计

角色子视图保存在角色资产的 `metadata.characterSubviews` 中，结构如下：

```ts
type FilmCharacterSubview = {
  id: string
  label: string
  kind: 'full_body' | 'portrait' | 'expression' | 'turnaround' | 'costume' | 'prop' | 'custom'
  sourceAssetId: string
  cropPx: { x: number; y: number; width: number; height: number }
  order: number
  createdAt: string
  updatedAt: string
}
```

说明：

- `sourceAssetId` 指向角色参考图对应的图片资产，而不是角色 prompt 资产本身。
- `cropPx` 使用原图像素坐标，避免受面板缩放影响。
- 首阶段不额外持久化导出的图片文件路径。

## 风险与规避

- 共享底栏入口与浮层状态容易和 3D 导演台冲突：
  - 只扩展底栏入口与统一浮层开关，不修改导演台面板内部逻辑。
- 角色资产本体是 prompt 资产而非 image 资产：
  - 统一通过 `references` 解析角色主参考图，再在该图片上做子视图裁切。
- 子视图应用到画布若直接覆盖原资产会破坏母卡：
  - 运行时生成新的图片资产并插入画布，母卡 metadata 仅保存裁切描述。

## 验收标准

- 底部工具栏可打开角色库面板，且与资产中心 / 导演台 / Agent 面板互斥。
- 面板能列出当前项目全部角色资产，并正确展示选中角色详情。
- 可以为角色创建、编辑、删除多个子视图，并持久化到角色资产 metadata。
- 应用子视图到画布时，会生成新的图片资产与图片节点，且不改动原角色卡。
