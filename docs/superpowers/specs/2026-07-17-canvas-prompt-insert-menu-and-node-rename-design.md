# 画布提示词插入菜单与节点改名交互设计

> 状态: 待开发 | 最后核对: 2026-07-17

## 背景与目标

操作节点当前缺少独立、易发现的改名入口；提示词“+”菜单与 `@` 菜单交互不一致，资源列表缺少搜索和内容预览，且弹窗关闭方式不完整。本次改造统一两条插入路径，并让节点名称成为独立配置。

目标：

- 在操作节点工作台中提供独立的节点名称编辑入口。
- 让“+”与 `@` 共用同一套可搜索、可筛选、可预览的选择器。
- 在不增加菜单主体高度的前提下补充角色、场景筛选入口。
- 支持点击外部、Esc 和完成选择三种关闭方式。

## 节点设置 Tab

操作节点工作台 Tab 顺序调整为：产物、运行历史、任务配置、节点设置。

“节点设置”只编辑当前操作节点名称：

- 初始值来自 `node.title`。
- Enter 或输入框失焦时保存；空白名称按 `null` 保存并恢复节点默认标题展示。
- Esc 放弃本次输入并恢复当前已保存名称。
- 未发生变化时不发起保存请求。
- 保存失败时保留用户输入并展示错误消息，便于重试。
- 节点切换或外部快照更新时，以最新节点名称同步编辑草稿。

任务配置面板不再重复展示标题字段；任务备注仍保留在任务配置中并沿用现有保存逻辑。

## 统一提示词插入选择器

新增一个由 `CanvasPromptComposer` 内部复用的统一选择器。“+”按钮和 `@` 触发器只负责提供不同的打开来源与初始查询，菜单内容、筛选、预览、选择和关闭逻辑保持一致。

### 打开与关闭

- 点击“+”时，以工具栏按钮为锚点打开菜单，搜索框初始为空。
- 输入 `@` 时，以编辑器光标为锚点打开同一菜单并聚焦搜索；`@` 后已输入的查询同步到搜索框。
- 点击菜单与预览层之外、按 Esc、或成功插入条目后关闭菜单。
- 从一个入口切换到另一个入口时复用同一打开状态，不叠加两个菜单。
- 菜单打开期间保持编辑器选区，选择条目后在原光标位置插入。

### 搜索与筛选

顶部固定一个紧凑搜索框，按名称、节点类型和可用文本摘要进行不区分大小写匹配。空查询展示全部可引用项目。

快捷参数改为单行五宫格：

- 添加镜头时长：直接插入时长参数。
- 添加台词：直接插入台词参数。
- 添加站位信息：直接插入站位参数。
- 添加角色：把下方列表筛选为角色节点与角色资源，不立即插入。
- 添加场景：把下方列表筛选为场景节点与场景资源，不立即插入。

角色或场景筛选可再次点击取消；切换筛选时保留搜索词。资源列表独立滚动，快捷区和搜索区保持可见。

### 外置悬浮预览

采用外置悬浮预览方案：菜单主体保持紧凑，鼠标或键盘高亮资源项时，在菜单右侧显示预览；右侧空间不足时自动翻转到左侧。预览不遮挡资源列表，也属于菜单交互边界，点击其中内容不会触发外部关闭。

预览内容按节点类型处理：

- 文本、提示词和带文本内容的资源：展示标题、类型与可滚动正文。
- 图片：展示较大尺寸图片、标题和类型。
- 视频：展示封面；没有封面时展示类型占位和基础信息。
- 音频及其他类型：展示标题、类型和可用摘要，不尝试自动播放。
- 内容缺失或资源已删除：展示明确空状态，不抛出渲染错误。

键盘上下选择与鼠标悬浮共享同一个高亮项，因此两种操作都会同步更新预览。

## 组件边界与数据流

- `CanvasOperationWorkbench` 负责新增 Tab、名称草稿和自动保存入口，复用现有节点保存回调，不引入新的持久化协议。
- `CanvasOperationPanel` 移除标题编辑控件，只保留任务配置草稿；现有运行与保存参数仍使用最新节点标题，避免任务执行覆盖已改名结果。
- `CanvasPromptComposer` 负责菜单打开来源、编辑器选区恢复与插入动作。
- 独立的提示词插入菜单组件负责搜索、分类筛选、结果高亮、外部点击和预览渲染，避免继续扩大编辑器主文件。
- 现有 mention item 构建与引用块创建逻辑继续作为单一数据来源；“+”与 `@` 不各自复制过滤规则。

数据流为：入口触发 → 保存插入位置与初始查询 → 统一菜单过滤并高亮项目 → 外置面板预览 → 插入参数或引用块 → 关闭菜单并恢复编辑器焦点。

## 兼容性与错误处理

- 不改变 `CanvasPromptDocument`、引用 relation 或节点持久化结构。
- 运行中的节点继续禁用名称修改和提示词插入。
- 没有可引用资源时仍展示快捷参数与空状态。
- 资源缩略图加载失败时回退到类型图标。
- 保存名称失败不关闭工作台，不覆盖用户输入。
- 菜单与预览使用稳定层级，避免被节点浮层或工作台裁切。

## 验证方案

- 单元测试覆盖节点名称 Enter、失焦保存、Esc 回退、空白名称和保存失败。
- reducer / 工作台测试覆盖新 Tab 顺序、无产物时仍可访问任务配置与节点设置。
- 提示词编辑器测试覆盖“+”与 `@` 共用菜单、搜索、角色/场景筛选、滚动结果、插入位置保持和关闭方式。
- 预览测试覆盖文本、图片、视频封面、缺失内容以及左右自动翻转所需的定位状态。
- 运行相关现有测试用于确认改名和菜单重构不改变提示词文档与任务提交结果。
- 最后执行 TypeScript 检查、相关 Vitest 测试和目标文件 diff 审查。

## 非目标

- 不新增节点别名、批量重命名或名称唯一性约束。
- 不改变画布内容节点的编辑弹窗。
- 不在预览中自动播放视频或音频。
- 不调整提示词引用的协议结构和任务编译规则。
