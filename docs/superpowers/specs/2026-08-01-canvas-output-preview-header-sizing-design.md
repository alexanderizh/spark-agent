# 画布产物预览头部与媒体尺寸设计

> 状态: 实施中 | 最后核对: 2026-08-01

## 背景

双击画布操作节点后，产物工作台在未全屏状态展示图片或视频。当前工作台头部依赖内容高度和自动网格行，预览媒体又会填满剩余区域，导致第二层 Tab 与第三层运行/产物操作栏在空间竞争时视觉上被压缩；大尺寸媒体也会让未全屏面板占用过多画布空间。

## 目标

- 第一层节点工具栏保持现有行为。
- 第二层 Tab 和第三层运行/产物操作栏各自使用固定 `40px` 行高，并禁止 flex 收缩。
- 容器变窄导致操作区域增加网格行时，每一行仍保持 `40px`，不因媒体尺寸改变。
- 预览区只消费头部之外的剩余空间，图片和视频保持原始宽高比并居中显示。
- 未全屏图片和视频使用紧凑的最大宽高；全屏状态解除该紧凑上限，继续利用全部可用空间。
- 文本、音频、分镜、配置、节点设置和运行历史布局不受媒体紧凑规则影响。

## 设计

工作台头部继续使用现有 CSS Grid，不拆分 React 组件。默认状态设置固定网格自动行高和不可收缩约束；在 `1100px` 以下的两行布局以及 `720px` 以下的多行布局中，所有自动生成行复用相同行高。Tab、上下文区和操作区填满所在行并垂直居中，横向内容继续使用现有滚动和省略规则。

未全屏媒体预览使用独立的尺寸上限，并通过预览容器居中。媒体设置 `max-width`、`max-height`、`width: auto`、`height: auto` 与 `object-fit: contain`，避免固有尺寸参与父级尺寸计算。全屏选择器覆盖这些上限并恢复 `width: 100%`、`height: 100%`。

## 验收

1. 未全屏打开含图片或视频的产物面板，第二层和第三层头部高度均稳定为 `40px`。
2. 切换不同宽高比、分辨率的图片和视频，头部高度不变化，媒体保持比例且不溢出。
3. 多产物标题过长或进入多选模式时，头部只发生横向滚动或省略，不发生纵向压缩。
4. 容器宽度低于 `720px` 时，新增网格行仍各为 `40px`。
5. 全屏后媒体可填满预览区，头部仍不可压缩。
6. 配置、节点设置、运行历史及非媒体产物保持原有布局和交互。

## 测试策略

- 增加样式契约测试，先证明当前样式缺少固定网格行高、不可收缩约束和未全屏媒体上限。
- 实现后运行该回归测试及 `CanvasOperationWorkbench`、`CanvasOperationOutputPreview` 相关组件测试。
- 运行桌面渲染端适用的类型检查或构建检查，并审阅最终 `git diff`，确保只触及预期文档、测试和样式。
