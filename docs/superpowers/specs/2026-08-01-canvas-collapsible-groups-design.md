# 无限画布编组折叠设计

> 状态: 已落地 | 最后核对: 2026-08-01

## 目标

无限画布中的编组支持持久化折叠。折叠后，组显示为紧凑的文件夹封面卡，组内节点与其关联连线暂时隐藏；双击封面卡即可恢复原始组尺寸、子节点布局和连线。

## 交互

- 展开组：双击组内空白区域折叠；右键菜单同时提供“折叠编组”。
- 折叠组：双击封面卡展开；右键菜单同时提供“展开编组”。
- 折叠卡仍可选中、拖动和打开右键菜单，但不显示缩放控件。
- 悬浮折叠卡时，两张顶部预览卡向上抽出约 16–20px，使用缓出动画；离开时回到插槽内。
- 旧项目没有折叠字段时保持当前展开行为。

## 视觉

折叠卡采用已确认的 A 方案：整体纵向比例略高，由后壳、图片插页和前挡板三层组成。前挡板顶边左高右低并使用柔和曲线过渡，使两张插页呈现不同的遮挡深度。主体保留编组图标、节点数量、组标题和右侧状态图标。

预览优先选择组内按 `createdAt` 倒序排列的两张图片节点。只有一张图片时，另一个位置显示默认小卡片；没有图片时，两个位置都显示默认小卡片。图片读取现有 `thumbnailUrl`，缺失时回退到 `url`。

## 数据与渲染架构

在 `CanvasNodeData` 增加可选字段 `collapsed?: boolean`。字段跟随现有节点数据持久化、历史记录和项目快照流转，不增加独立存储结构。

折叠只改变 React Flow 投影，不修改持久化的组 `width`、`height` 和子节点坐标：

1. 从画布快照收集 `data.collapsed === true` 的组。
2. 计算这些组的全部后代节点 ID。
3. 构建 Flow 节点时过滤后代节点，并把折叠组投影为固定紧凑尺寸。
4. 构建 Flow 边时过滤端点属于隐藏后代的边；组自身的业务连线继续显示。
5. 展开只需把 `collapsed` 更新为 `false`，下一次投影直接恢复原始布局。

折叠投影、后代收集和封面预览选择放在独立纯函数模块中，折叠卡样式也拆到独立 Less 文件，避免继续扩大现有大型画布文件。`CanvasStage.tsx` 负责使用投影结果，`CanvasNode.tsx` 只负责折叠卡渲染和交互接线。

## 状态更新

折叠与展开复用现有不可变节点数据更新入口。动作通过 `actions.updateNodeData(node.id, { collapsed: next })` 提交，使项目快照保存、撤销/重做和刷新行为与其他节点数据一致。组双击时优先切换折叠状态，不再进入普通节点编辑动作；非组节点维持现有双击编辑行为。

## 边界与降级

- 折叠组为空时仍显示两个默认小卡片和 `0 个节点`。
- 预览图片无法加载时单个插页降级为默认小卡片，不影响组展开。
- 子组折叠状态独立保存；父组折叠时整个后代树隐藏，父组展开后恢复子组先前状态。
- 折叠状态不会改变节点血缘、任务输入解析、合成组图片或 Agent 工具看到的真实画布快照。
- 折叠组拖动继续依赖 React Flow 的父子节点机制，子节点相对位置不被改写。

## 测试与验收

- 纯函数测试覆盖：折叠组后代收集、嵌套组、边过滤、最近两张图片选择、默认卡片补位和旧节点默认展开。
- 组件测试覆盖：折叠卡内容、双击展开/折叠、折叠时禁用缩放控件、非组节点双击行为不变。
- 样式源码断言覆盖：三层结构、左高右低边缘、悬浮抽出动画及减少动态效果偏好。
- 定向测试通过后运行 Desktop 类型检查和相关画布测试；最后检查 `git diff` 与 GitNexus 变更影响。

## 非目标

- 不修改组成员关系或 `group_contains` 语义。
- 不在折叠态重接子节点的外部连线到组节点。
- 不增加预览图手动排序、封面编辑器或新的全局偏好。
