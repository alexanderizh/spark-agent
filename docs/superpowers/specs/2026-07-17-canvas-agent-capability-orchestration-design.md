# 画布 Agent 能力编排设计

> 状态: 已落地 | 最后核对: 2026-07-29

## 目标

让画布侧面板中的 Agent 能从当前画布实时发现节点能力、右键等价动作和影视制作阶段，优先复用画布节点与既有资产，按照推荐生产流程创建可检查的操作节点，而不是脱离画布随意生成。

## 问题

当前 UI 右键菜单、`spark_canvas` 工具 schema、画布 Skill 和制作进度提示分别维护能力知识。Agent 能看到原子工具，却无法稳定回答“这个节点现在能做什么”，也缺少分集、资产齐套、重点场景全景图等阶段判断。

## 设计

### 动态能力发现

新增只读工具 `canvas_get_available_actions`。它根据最新快照和目标节点返回：动作 id、名称、分类、执行方式、前置条件、输入输出语义和等价工具建议。流水线动作直接复用 `CANVAS_PIPELINE_OPS`，通用媒体操作复用节点生成菜单目录，UI 专属动作明确标为需要用户交互。

### 制作计划

新增只读工具 `canvas_get_production_plan`。它基于资产、节点、任务、文稿章节和分镜分组生成当前阶段、阻塞项、推荐下一步和标准流程。标准顺序为：文稿/剧本、角色与场景、身份板与场景图、重点场景全景、分集、按集分镜、镜头资产齐套、关键帧、视频节点、EDL。

### Agent 行为约束

画布助手在宽泛创作请求中先读取项目摘要和制作计划，在针对节点的请求中先查询可用动作。默认只创建并配置操作节点；只有用户明确要求立即执行时才运行媒体任务。结果必须保留节点、资产、集数和分镜血缘。

### 侧栏交互与可靠性

- 首轮提交前必须等待 `canvas:host-attach` 完成；侧栏展示连接中、已连接、断开状态，并提供手动重连。
- 打包版的 `spark_canvas` stdio 脚本必须以 `extraResources` 放在 `Resources/tools`，不得让独立 Node 进程执行 `app.asar` 内路径；开发态继续使用源码目录回退。
- 已绑定画布的 Codex 或 Claude SDK 会话若无法解析或启动 `spark_canvas`，必须在模型执行前以 `CANVAS_MCP_UNAVAILABLE` 失败并明确说明本轮未修改画布，不得静默降级为 Bash 或数据库直写。
- 顶部自动保存开关旁提供手动刷新按钮。刷新从持久化快照重新加载当前画布；存在未保存修改时必须先确认，确认后丢弃热状态并清空旧的撤销、重做和 Agent turn 检查点。
- 同一轮的 reasoning 片段合并为一个思考区，画布工具调用合并为紧凑执行记录；执行记录只展示 `spark_canvas` 工具，并用业务动作名称、状态、耗时和节点定位入口表达过程。
- 对话按 turn 分组展示时间和完成状态；失败或取消轮次可以重试，完成回复可以复制。
- 嵌入式历史按完整轮次向上分页，加载失败必须在面板内可见并可重试；流式输出仅在用户位于底部时自动跟随，离开底部后显示新动态计数。
- 引用节点和工具结果中的节点 id 可以直接选中并聚焦画布。
- 每个 Agent turn 提交前记录画布快照；仅当该轮成功执行写工具时展示“撤销本轮画布修改”。快照恢复会明确告知用户：该轮执行期间的手动修改也会一并还原。

### 单画布分集

分集不创建新画板。第一阶段以现有剧本节点、分组和分镜组命名表达集数；后续数据模型统一增加 `episodeId` / `episodeNumber`，逐步移除旧 `FilmEpisode.boardId` 语义。

## 边界

- 第一阶段提供准确的能力发现和推荐计划，不让 Agent 直接打开标注器、全景预览或 3D 导演台等交互式 UI。
- UI 专属动作返回清晰入口；可无歧义映射到现有工具的动作返回工具配方。
- 不向超过 3000 行的文件增加业务逻辑；只允许薄接线，新增逻辑进入独立模块。

## 验收

- Agent 能查询普通文本、剧本、角色、场景、分镜、图片、视频节点的可用动作。
- Agent 能区分可直接工具执行、创建待确认节点、必须用户操作 UI 三种动作。
- 空项目、已有剧本、已有分镜三类项目能得到不同的下一步建议。
- 推荐流程包含角色身份板、场景图、重点场景全景、分集、按集分镜、资产齐套、关键帧和视频节点。
- 画布 Skill 和内置助手 Prompt 明确要求优先使用节点能力和动态规划工具。
- 打包产物中的 `Resources/tools/spark-canvas-mcp-server.mjs` 可由随应用分发的 Node 运行时直接启动，不依赖 Electron 的 asar 文件系统补丁。
- 已绑定画布但工具运行时不可用时，Agent 不进入模型执行并展示可重试错误；工具可用时节点写入通过画布桥实时回传快照，无需关闭重开画布。
- 手动刷新可重新读取外部或恢复后的持久化变更；刷新期间不可重复触发，保存期间按钮禁用，未保存修改不会被无提示覆盖。
