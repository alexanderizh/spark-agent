# 无限画布产品 UI/UX V3 设计规范

> 状态: 已废弃 | 最后核对: 2026-07-13

本版已由更简约、扁平化且补齐预设中心与大型弹窗规则的 [V4 实施计划](../plans/2026-07-13-canvas-uiux-v4-implementation-plan.md) 取代。

## 1. 设计范围

V3 不再把无限画布理解为“画布 + 一组卡片”，而是统一设计以下九个产品场景：

1. 节点系统：内容节点、媒体节点、任务节点、工作台节点、组与全状态。
2. 视频工作台：视频监看、逐帧控制、关键帧、剪辑、产物、专业时间线。
3. 3D 工作台：场景树、对象添加、视口、变换、姿势、镜头约束和 Shot List。
4. 资产中心：全局资产治理、搜索过滤、资产卡片和深度预览。
5. 生成配置：输入、模型、提示词、输出设置和运行前预检。
6. 右侧面板：属性、任务、资产、项目四个上下文 Tab。
7. Agent 助手：画布上下文、执行计划、工具调用、进度和可中断运行。
8. 项目资产中心：角色、场景、道具、分镜、视觉圣经和版本历史。
9. 项目卡片：制作进度、最后工作现场、活动状态和快捷继续。

交互原型：[`docs/design-prototypes/canvas-uiux-v3/index.html`](../../design-prototypes/canvas-uiux-v3/index.html)

## 2. 产品视觉方向

采用“专业影像制作系统”方向。画布和工作台均使用冷黑、石墨绿中性色；荧光薄荷色只表示当前操作、运行或成功；琥珀表示待确认；红色表示需要处理；青色、紫色和玫瑰色只承担类型导航。

核心原则：

- 内容预览的视觉权重高于容器和标签。
- 状态必须同时通过文字、图形和位置表达，不依赖颜色。
- 所有专业工作台共享顶栏、侧栏、Inspector、底部轨道语言。
- 同类动作在不同场景保持位置与命名一致。
- 控件密度适配桌面创作，不使用移动端式大按钮堆叠。

## 3. 基础设计 Token

### 3.1 空间

基础单位为 4px。常用间距为 4 / 8 / 12 / 16 / 24 / 32px。节点标题栏 38–40px，工作台顶栏 48–52px，侧边面板一级 Tab 38–42px。

### 3.2 圆角和边框

- 节点：8–10px。
- 工作台 / 大型弹窗：10–12px。
- 按钮和输入：5–7px。
- 主分割线：1px、11% 白色透明度。
- 选中线：1px 薄荷色 60% + 3px 低透明度外环。

### 3.3 字体层级

- 场景标题：15–20px / 700。
- 工作台标题：11–14px / 650。
- 节点标题：11–12px / 650。
- 正文和表单：11–13px。
- 元数据：9–10px 等宽字族。

## 4. 节点系统

### 4.1 统一结构

每个节点包含：

1. 左右连接端口。
2. 38–40px 控制标题栏。
3. 主内容区域。
4. 28–32px 上下文底栏。
5. 选中、运行、错误等覆盖反馈层。

标题栏只显示类型、标题、版本或模型，以及一个主状态。产物、角色和来源等次级信息移到底栏或 Inspector，避免徽标堆叠。

### 4.2 推荐尺寸

| 节点 | 推荐尺寸 | 最小尺寸 | 行为 |
| --- | ---: | ---: | --- |
| 短文本 / Prompt | 360×260 | 300×180 | 内部阅读，超过阈值升级为文档节点 |
| 长文稿 / 剧本 | 720×560 | 560×360 | 固定阅读宽度，正文滚动 |
| 分镜脚本表 | 980×620 | 760×460 | 表格列保持可读，不退化为便签 |
| 图片资产 | 540×340 | 320×220 | 保持媒体比例，底栏不计入图片比例 |
| 视频资产 | 580×360 | 400×240 | 预览、时间码、工作台入口 |
| 音频资产 | 420×220 | 320×160 | 波形、时长、采样率 |
| 任务节点 | 520×480 | 420×340 | 运行时不因产物比例改变外框 |
| 工作台入口 | 560×360 | 420×280 | 展示最近现场与继续入口 |
| 多产物组 | 内容驱动 | 250×44 收起态 | 2–9 个均匀网格，超过 9 个分页 |

### 4.3 运行边框动效

运行态使用两层边框，而不是让整个节点闪烁：

- 外层：2px 高亮轨迹沿边框顺时针运行，周期 1.85s，头部接近白色，尾部逐渐透明。
- 内层：1px 薄荷色边框以 1.2s 周期在 35%–60% 透明度间呼吸。
- 辅助：最多两个 5px 光点沿顶部和底部边缘追踪。
- 内容区可使用局部扫描带，但透明度不得超过 15%。
- 任务完成后轨迹在 280ms 内收束，保持完成亮边 1.2s 后恢复常规状态。
- `prefers-reduced-motion` 下取消运动，只保留静态双层运行边框与状态文字。

动效只使用 `transform`、`opacity` 和遮罩角度，禁止持续动画节点尺寸和大面积阴影模糊。

### 4.4 节点状态

- `empty`：说明正在等待的输入，并给出主要行动。
- `ready`：中性边框，运行按钮可用。
- `queued`：显示队列位置和预计开始时间。
- `running`：动态边框、阶段、进度、耗时、当前产物序号。
- `review`：琥珀状态，强调需要人工确认。
- `completed`：显示主产物、运行摘要和展开入口。
- `failed`：展示可理解原因和修复动作，不持续抖动。
- `cancelled`：降低饱和度，保留重新运行。
- `stale`：说明是哪一个上游更新导致过期。

### 4.5 多产物组

- 任务节点保留缩略图摘要和产物数量。
- 一个产物直接物化到任务右侧。
- 2–9 个产物创建独立产物组，使用接近方形的均匀网格。
- 支持主产物、批量展开、批量插入下游和按 Run 折叠历史。
- 收起态为 250×44 摘要条，数据和血缘不改变。
- 多次运行不能覆盖旧产物；新 Run 插入在组顶部。

## 5. 视频工作台

视频工作台使用全屏专业编辑布局：

- 顶栏：工作台名称、版本、视频规格和保存到画布。
- 主区左侧：监看画面、Safe Area、帧号和缩放。
- 主区右侧：关键帧 / 剪辑 / 产物三个 Tab。
- 底部：视频轨、音频轨、标记轨和时间标尺。

关键帧 Tab 提供自动取帧策略、敏感度、主帧标记和批量导出。剪辑 Tab 提供入点、出点、变速和输出格式。产物 Tab 区分可播放视频、关键帧包和处理记录，并可以插入画布或展开为组。

## 6. 3D 工作台

3D 工作台使用四区结构：

- 左侧：场景树、角色 / 道具 / 灯光分类和快速添加。
- 中央：3D 视口、变换工具、构图线和视口统计。
- 右侧：对象 / 材质 / 姿势 Inspector。
- 底部：Shot List，承载机位、焦段、时长和批量导出。

右侧 Inspector 将角色“变换”“表演与姿势”“镜头约束”分开，避免关节滑杆和通用属性混在一个长列表里。构图健康度以可解释指标呈现：三分线、视线空间、头顶空间等。

## 7. 资产中心与资产预览

全局资产中心采用三栏布局：

- 左侧：资源范围、收藏、引用状态和项目文件夹。
- 中央：可切换网格 / 列表的虚拟化资产浏览区。
- 右侧：深度预览、基本信息、引用、版本和生成血缘。

资产卡片需要显示：真实比例缩略图、类型、时长、标题、标签、尺寸、引用数和收藏状态。悬停时出现“插入画布”和“预览”，不常驻三个以上图标按钮。

右侧预览支持图片缩放、视频播放、音频波形、文本阅读和失效引用修复。资产必须能从来源任务追溯到画布节点，也能定位全部使用位置。

## 8. 生成配置弹窗

配置改为四步：输入素材 → 模型与参数 → 提示词 → 输出设置。

弹窗包含：

- 左侧步骤和配置完整度。
- 中央当前步骤表单。
- 右侧输出预览、耗时 / 费用估算、兼容性警告和放置摘要。
- 底部全局动作。

模型参数按常用、高级和自定义分层。模型不支持的参数直接隐藏或禁用并说明原因。运行前必须预检素材比例、必填输入、模型兼容性、预计输出数量和落点空间。

## 9. 右侧面板

右侧面板四个 Tab：

- 属性：当前选区、节点预览、基础信息、布局、血缘。
- 任务：运行任务、待提交任务和历史任务。
- 资产：当前项目资产的轻量插入器。
- 项目：制作进度、视觉总设定和项目级配置。

Tab 头保持固定，内容独立滚动，底部历史 / 目录 / 模板 / 快捷键保持固定。多选时属性 Tab 切换为批量操作和选区摘要，不展示第一个节点的单体字段。

## 10. Agent 助手

Agent 面板必须让自动操作可观察、可中断、可恢复：

- 明确展示当前项目会话和已引用节点。
- Agent 在修改画布前输出执行计划。
- 每个步骤显示 waiting / running / completed / failed。
- 工具调用折叠显示参数摘要和结果，错误可重试。
- 自动放置前显示预计占用区域；批量操作完成后提供定位和撤销。
- 运行中发送按钮变为停止按钮，并保留用户补充要求的入口。
- Composer 固定展示 Agent、模型、Skills 和引用节点。

## 11. 项目资产中心

项目资产中心以 Production Bible 为核心，不与全局资产中心重复：

- 角色、场景、道具、分镜、视觉圣经和版本历史作为一级 Tab。
- 角色卡片展示状态、身份、标签、参考图数和引用数。
- 详情面板展示视觉锚点、一致性检查、子视图和使用位置。
- 分镜 Tab 使用左侧镜头组 + 中央表格 / 卡片 + 右侧镜头详情。
- 上游变化导致资产过期时，明确显示来源和刷新动作。

## 12. 项目卡片

项目列表的首要目标是“继续工作”。置顶项目使用大卡片展示：

- 最后活跃时间和最后工作现场。
- 制作阶段进度。
- 节点、资产和运行任务数量。
- 协作者 / Agent 状态。
- 明确的继续创作入口。

普通项目卡片展示封面、业务类别、活跃状态、完成度、更新时间和节点数。更多菜单只放管理动作，不把“打开”藏进菜单。

## 13. 统一放置 UX

所有入口复用同一个 placement transaction：工具栏、菜单、拖入、资产插入、Agent、任务创建、产物完成、复制粘贴、分镜展开和组展开。

每次批量添加先完成内部布局，再以批次包围盒搜索空位。现有节点、组框、浮动面板和并发任务预留区都属于障碍物。默认安全间距为 56px；优先放在来源右侧，其次下方，再按确定性方形环扩展。

放置完成后需要：

- 180–300ms 的批次进入动画。
- 视口平移保证至少 35% 新内容可见。
- 提供一次性撤销。
- 不擅自缩放用户画布。
- 并发任务提前预留预计产物区域。

## 14. 实施分期

1. 设计 Token、节点框架、状态与动效。
2. 统一放置事务、多产物组和节点推荐尺寸。
3. 右侧面板、配置弹窗和 Agent 助手。
4. 视频工作台与 3D 工作台。
5. 全局资产中心、项目资产中心和项目卡片。
6. 性能、键盘操作、减弱动效和视觉回归验收。

现有 `CanvasWorkspaceView.less` 已超过 13,000 行，V3 样式必须拆分为独立模块，禁止继续堆入该文件。特殊工作台保持独立样式文件，并抽取共享 Workbench Shell 和 Inspector Token。
