# 画布新手引导教学中心设计

> 状态: 待开发 | 最后核对: 2026-07-18

## 背景与目标

画布已经具备文稿、影视资产、分镜、图片与视频任务、预设中心、3D 导演台、画布 Agent、项目资产和任务排错等能力，但首次进入时缺少完整且可执行的学习路径。新用户很难判断应该先做什么，也难以从已有工具入口理解一套从文稿到画面的推荐流程。

本功能在画布加载完成后自动展示一个大尺寸的新手引导弹窗，使用扁平化深色一体视觉。引导不只说明功能，还提供跳转到真实画布能力的入口。

成功标准：

- 首屏只展示四个一级创作步骤，用户可以在一个视野内理解主流程。
- 二级能力只在对应步骤的专属教学页展示，不增加首屏复杂度。
- 预设中心、3D 导演台、画布 Agent、项目资产、任务参数和错误排查都有独立教学与可执行入口。
- 用户可以勾选“下次打开画布时不再自动展示”，该偏好对所有画布项目全局生效。
- 用户关闭自动展示后，仍可从画布帮助入口手动重新打开。

## 范围

本轮包含：

- 新手引导大弹窗、快速开始首页、四个流程专属页和核心工具教学页。
- 全局展示偏好与手动重开入口。
- 教学入口与现有画布面板、弹窗和节点操作的连接。
- 错误排查时打开任务列表与左侧 Agent，并准备待确认的排错提问。
- 组件测试、偏好测试和必要的画布集成测试。

本轮不包含：

- 真实画布上的逐控件遮罩、聚光灯或气泡巡游。
- 服务端同步新手引导进度。
- 按项目分别记录完成状态。
- 自动执行生成任务、自动发送 Agent 消息或替用户修改画布内容。
- 新建画布操作、影视资产或持久化协议。

## 信息架构

### 快速开始首页

首屏只保留四个一级步骤：

1. 导入文稿。
2. 提取资源。
3. 提取分镜。
4. 选中资源生成视频或图片。

每个步骤只展示一句结果导向说明和“进入步骤”入口。首页不直接展示角色板、360 场景或手动优化分镜。

首页下方提供六个能力速查入口：

- 预设中心。
- 3D 导演台。
- 画布 Agent 助手模式。
- 项目资产中心。
- 任务参数配置。
- 错误查看与 Agent 排查。

### 流程专属教学页

四个步骤分别拥有专属页面，统一使用“目的说明、建议顺序、教学项、立即体验、上一步、下一步”的结构。

#### 导入文稿

- 说明支持从本地文件或文本内容建立项目文稿。
- “立即体验”关闭引导，打开项目资产中心的“文稿”页签。

#### 提取资源

- 一级教学项：从文稿或剧本提取角色、场景、道具和特效。
- 二级可选项：分拆角色板子视图。
- 二级可选项：生成场景 360 全景图。
- 角色板和 360 场景只出现在本专属页，不出现在快速开始主流程。

#### 提取分镜

- 一级教学项：从文稿或剧本提取结构化分镜脚本。
- 后续教学项：手动优化镜号、景别、机位、镜头运动、时长、表演和画面描述。
- 手动优化只出现在本专属页，不出现在快速开始主流程。

#### 生成视频或图片

- 说明先选中资源节点、分镜节点或已有画面，再选择对应生成动作。
- 说明任务参数在提交前配置，生成结果会回到画布并保留来源关系。

### 任务与错误排查页

该页使用三步说明：

1. 在右侧“任务”面板找到失败任务并查看错误摘要。
2. 定位对应画布节点，将节点和错误上下文加入左侧 Agent。
3. 在 Agent 输入区确认预置问题后再发送，不自动发消息。

“开始排查”优先选择最近一个失败任务；没有失败任务时只打开任务面板和 Agent，并展示“当前没有失败任务”的非阻塞提示。

## 视觉设计

- 采用深色一体化扁平设计，与画布强制深色工作区保持一致。
- 弹窗默认约 `1180 × 720`，最大宽高受视口约束；窄窗口时内容区滚动，流程卡从四列降为两列或单列。
- 背景使用深灰层级和细边框区分区域，不使用高光玻璃、厚重渐变或拟物装饰。
- 紫色只用于当前导航、步骤编号、可执行链接和主按钮。
- 可选教学项使用中性标签，不与错误、完成等状态色混用。
- 左侧导航固定，右侧教学内容滚动；底部偏好和主要操作保持可见。
- 所有图标复用现有 `Icons`，不引入表情字符或新的图标依赖。

## 打开、关闭与全局偏好

新增版本化偏好键：

```text
spark-canvas:onboarding-guide:dismissed:v1
```

规则：

- 任意画布项目首次完成快照加载后，如果全局偏好未关闭，则自动打开引导。
- 偏好不包含 `projectId`，因此对所有画布项目生效。
- 勾选“不再自动展示”后，无论通过关闭按钮、“稍后探索”、“开始创作”还是教学跳转关闭弹窗，都写入关闭偏好。
- 未勾选时关闭弹窗不写入偏好，下次进入任意画布仍自动展示。
- 手动打开时复用同一弹窗；已关闭自动展示的用户可以取消勾选并关闭，从而恢复后续自动展示。
- 读取或写入 `localStorage` 失败时仅影响持久化，当前会话仍能正常打开和关闭。
- 偏好版本升级时使用新键，可让重大教学改版重新展示；本轮不自动迁移旧版本。

引导只在 `snapshot` 存在后渲染，避免盖住加载和“画布不存在”状态。自动打开在每次组件挂载时只判定一次，避免快照刷新导致反复弹出。

## 可执行入口与上下文处理

引导组件不直接操作画布 store。它只派发语义动作，由 `CanvasWorkspaceView` 适配到现有回调和面板状态。

建议的动作集合：

```ts
type CanvasOnboardingAction =
  | 'open_manuscript'
  | 'extract_resources'
  | 'open_character_board'
  | 'open_panorama'
  | 'extract_storyboard'
  | 'edit_storyboard'
  | 'generate_media'
  | 'open_presets'
  | 'open_stage_3d'
  | 'open_agent'
  | 'open_assets'
  | 'configure_task'
  | 'diagnose_error'
  | 'open_shortcuts'
```

动作分三类处理：

1. **可直接打开**：关闭引导并打开目标功能，如预设中心、3D 导演台、Agent、资产中心和文稿页签。
2. **需要选中节点**：优先使用当前合格选区；没有合格节点时打开最接近的资产或任务面板并给出选择提示，不自动创建或运行任务。
3. **需要失败上下文**：选择最近失败任务对应节点，加入 Agent 引用并预填排错问题；问题只进入草稿，不自动发送。

具体映射：

| 教学动作 | 有可用上下文 | 无可用上下文 |
| --- | --- | --- |
| 导入文稿 | 打开影视资产中心“文稿”页 | 同左 |
| 提取资源 | 定位文稿/剧本节点并展示已有资源提取动作 | 打开文稿页并提示先导入或选择文稿 |
| 角色板 | 打开所选角色图片的子视图编辑/生成入口 | 打开角色资产页并提示选择角色图 |
| 360 场景 | 打开所选场景图片的全景生成入口 | 打开场景资产页并提示选择场景图 |
| 提取分镜 | 定位文稿/剧本节点并展示分镜提取动作 | 打开剧本或分镜页并提示选择来源 |
| 手动优化分镜 | 打开所选分镜脚本编辑器 | 打开分镜分组页并提示选择分镜 |
| 生成视频/图 | 打开所选节点的生成动作或参数面板 | 回到画布并提示先选中资源节点 |
| 任务参数 | 打开所选任务节点的配置面板 | 打开任务页并提示选择任务节点 |
| 错误排查 | 选中最近失败节点、打开任务页和 Agent、预填问题 | 打开任务页和 Agent，提示当前无失败任务 |

动作执行前先关闭引导，避免目标面板出现在遮罩下。跳转失败时保留画布可用状态并显示普通错误消息，不重新强制打开引导。

## 组件边界

`CanvasWorkspaceView.tsx` 已超过 9000 行，本功能不把教学内容和样式继续写入该文件。新增模块建议如下：

- `CanvasOnboardingGuide.tsx`：弹窗外壳、导航、页面切换、偏好勾选和动作派发。
- `CanvasOnboardingGuide.less`：深色扁平视觉、响应式布局和交互状态。
- `canvasOnboardingContent.tsx`：四个步骤页、工具页和排错页的静态内容配置与图标映射。
- `canvasOnboardingPreferences.ts`：版本化偏好的安全读写。
- `canvasOnboardingActions.ts`：动作类型、上下文解析和不依赖 React 的选择逻辑。

`CanvasWorkspaceView.tsx` 只新增：

- 引导打开状态与一次性自动判定。
- 语义动作到现有面板、选区和回调的适配函数。
- 引导组件挂载。
- 帮助入口的手动打开回调。

现有底部“画布帮助 / 快捷键”入口改为打开新手引导；引导内提供“快捷键速查”入口，再打开现有快捷键弹窗，避免丢失旧功能。

为支持错误排查，`CanvasAgentModal` 增加受控的草稿预填请求，使用 `nonce` 防止相同文本在普通重渲染时重复覆盖用户输入。预填只发生在用户点击“开始排查”后。

## 可访问性与边界状态

- 复用 Ant Design `Modal` 的焦点锁定、Esc 关闭和遮罩行为。
- 导航使用按钮和 `aria-current="page"`；步骤页标题与弹窗标题建立可访问名称。
- 所有“立即体验”按钮有清晰动词，不只用图标表达。
- 不满足前置条件的动作不静默禁用；按钮仍可点击，并将用户带到准备上下文的位置。
- 小窗口保证关闭按钮、偏好和主操作可达，内容不产生横向溢出。
- 动效只使用短距离淡入和颜色变化，并尊重 `prefers-reduced-motion`。

## 测试与验收

单元测试：

- 全局偏好缺省、关闭、恢复、存储异常和版本隔离。
- 首屏只有四个主步骤，不出现角色板、360 场景和手动优化分镜。
- “提取资源”专属页展示角色板和 360 场景；“提取分镜”专属页展示手动优化。
- 勾选状态在所有关闭路径上正确写入或移除偏好。
- 语义动作对不同选区、无选区和失败任务上下文的解析。
- 错误排查只预填 Agent 草稿，不自动发送。

组件与集成测试：

- 快照加载后自动展示一次，刷新快照不会重复打开。
- 手动帮助入口可以在关闭自动展示后重新打开。
- 预设中心、资产中心、Agent、3D 导演台和快捷键跳转正确。
- 需要节点的动作在有上下文时打开目标，在无上下文时显示明确提示。
- 键盘关闭、焦点顺序和窄窗口滚动可用。

验证命令：

- 运行新增引导、偏好和动作测试。
- 运行受影响的画布 Agent、底部 Dock、影视资产中心和工作区集成测试。
- 运行桌面端 TypeScript 类型检查。
- 运行 `git diff --check`。
