# 平台官方模型本机偏好与显示修复设计

> 状态: 已落地 | 最后核对: 2026-07-12

## 范围

修复平台官方 Provider 的额度单位、品牌图标和会话 ID 校验，并允许用户只在本机 Spark-Agent 中启用或隐藏模型、选择默认模型。

## 数据边界

- NewAPI 返回的完整模型列表保存为 `availableModelIds`。
- 本机启用项继续使用 Provider 的 `modelIds`，默认模型使用 `defaultModel`。
- bootstrap 只移除服务端已下架的本机选择，不把新模型自动塞回已有自定义偏好。
- 地址、API Key、账号和远端令牌范围仍由系统托管，设置弹窗不提供这些字段。

## 额度与媒体

额度通过 NewAPI 公共状态接口获得站点的点数基数、展示币种和汇率后换算。视频等异步媒体模型不进入当前文本 Provider；未来按能力元数据建立独立受管媒体 Provider。
