# 无限画布预设中心重设计

> 状态: 已落地 | 最后核对: 2026-07-16

## 目标

把当前按节点类型平铺、同时暴露 Agent、Provider、模型、提示词和参数的预设弹窗，重构为普通用户能直接理解的“任务默认 + 节点覆盖”双层设置。

成功标准：

- 首屏分别设置文本处理、图片理解、图片生成、视频生成的通用默认。
- 文本处理先选择“交给 Agent”或“直接用模型”，不再把 Agent 与模型表现成两个同级必填项。
- 节点设置作为第二层覆盖方案；未覆盖节点明确显示“继承默认”。
- Agent 使用头像，模型选择展示 Provider / 模型图标、名称和必要能力提示。
- 旧节点预设继续生效，并真实覆盖新增的任务默认。

## 信息架构

弹窗标题改为“画布默认设置”，主体使用两个页签：

1. `按任务类型`：默认页，以两列任务卡展示四类高频默认。
2. `按节点覆盖`：按文本、图片、视频、音频分组展示节点功能类型，徽标显示覆盖数量。

底部只保留“取消”和“保存默认设置”。恢复动作移动到具体节点编辑区，避免用户误解恢复范围。

## 任务默认

- `文本处理`：文本生成、改写、提示词优化和文本流水线。支持 Agent 或直接模型，并可选择 Skills。
- `图片理解`：带图片输入的文本任务。只展示支持图片输入的多模态文本 Provider / 模型。
- `图片生成`：文生图、图生图、编辑、合成、故事板和 360 全景图。
- `视频生成`：文生视频、图生视频、视频编辑和视频扩展。

通用图片与视频卡只保存模型身份，不传播可能不兼容的尺寸、比例、时长等参数。音频任务本轮继续在节点覆盖中独立设置。

## 节点覆盖与优先级

旧的 `CanvasPresetTargetId` 存储继续作为节点覆盖层，不迁移、不删除。新增任务默认存储只保存 `agentId`、`providerProfileId`、`manifestId`、`modelId` 和 `skillIds`。

解析优先级为：

1. 当前任务或节点显式配置；
2. 最近一次使用配置；
3. 节点功能覆盖；
4. 任务类型默认；
5. 平台内置默认。

文本操作收到图片输入时使用图片理解默认；节点覆盖和显式运行配置仍优先。

## 视觉与状态

- 延续深色中性主题，以单一低饱和黄绿色表示已设置和主要保存动作。
- 卡片只保留当前生效值与一个“更多设置”入口，高级提示词和参数默认折叠。
- 模型选择器复用现有 Provider 图标体系；图标缺失时使用现有模型回退图标。
- 保留加载、空状态、保存失败、脏草稿关闭保护与窄窗口单列布局。
- 文案不出现 manifest、runtime、preset target 等内部术语。

## 测试

- 任务分类、存储归一化和节点覆盖优先级。
- 带图片输入的文本任务选择图片理解默认。
- 首屏四任务卡、双页签、Agent / 模型切换、节点继承与统一保存。
- 定向 Vitest、桌面端 TypeScript 类型检查和 `git diff --check`。
