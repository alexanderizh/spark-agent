# 画布节点内快捷操作、比例尺寸联动与参数聚合设计

> 状态: 已落地 | 最后核对: 2026-08-08

## 背景

画布已经具备节点浮动工具条、节点配置面板、模型参数预览、Schema 驱动参数控件和媒体节点尺寸拟合能力。本次改造复用现有操作回调和动态右键菜单，并在选中节点顶部补充图标工具栏，不新增第二套业务状态：

1. 空内容节点和缺少媒体输入的任务节点，在节点内容区直接提供简单文字操作。
2. 图片/视频生成任务节点根据当前画幅参数调整卡片宽高。
3. 现有参数配置面板把常用任务参数聚合展示，不再要求逐项打开独立参数弹层。

## 目标

- 用户无需记住“双击”或先打开外部工具条，就能在空节点内开始编辑、上传或选择输入。
- 修改图片/视频生成比例时，节点外形立即传达 16:9、1:1、9:16 等画幅趋势。
- 比例、清晰度、时长、生成音频、生成数量等常用参数在现有配置面板中一次完成调整。
- 继续以模型 capability Schema 为参数字段唯一事实源，不改变 Provider 请求、参数裁剪、任务提交和产物落盘语义。

## 非目标

- 不新增第二套节点业务操作状态、独立菜单协议或画布全局工具条；选中态顶部工具栏只作为现有右键动作的图标化入口。
- 不新增“调整参数”按钮、参数摘要或第二层配置浮层。
- 不复制 `modelParamDraft`，不创建独立的参数保存协议。
- 不修改媒体 Provider、Manifest、Adapter 或 Validator 的字段语义。
- 不根据通用猜测补出模型 Schema 未声明的参数。

## 交互设计

### 选中节点顶部工具栏

单选节点时，在节点顶部显示显式白名单内的图标工具栏。工具栏使用 Lobe `Button` 的 `type="text"` 形态，按钮只显示图标，操作名称通过 Tooltip 和无障碍标签提供。节点类型、任务产物和可用回调决定实际显示项；工具栏不自动镜像右键菜单，视频编辑、影视创作（流水线/创建任务）、资源库、类型切换和编组管理继续保留在右键菜单。

- 工具栏按明确迁移项显示提交运行、全景预览、展开产物、复制、素材/音频操作；这些单节点快捷项从右键菜单移除。视频编辑、影视创作（流水线/创建任务）、资源库、类型切换和分组操作不迁移，只保留在右键菜单。
- “添加到 Agent 对话”继续只保留在右键菜单中；删除节点同时在工具栏末尾提供危险色图标按钮，并保留右键菜单入口。
- 单选与多选工具栏统一使用 36px 外层高度和 28px 图标按钮；音频节点及音频任务产物的截取、变速、下载入口并入该工具栏，不再额外渲染一排节点内音频工具栏。
- 工具栏按钮复用现有 `CanvasNode` actions，并阻止拖拽/选区事件冒泡，不改变节点数据协议。

多选节点时隐藏每个节点自身的工具栏，只显示跟随选区包围盒的多选工具栏。多选工具栏使用纯图标按钮，并按多选右键菜单的可用条件动态显示：提取工作流、批量配置参数、批量提交运行、添加到 Agent 对话、复制、创建组、合并为组合图和删除；对齐与网格排列继续作为选区专属操作保留。提取工作流、批量提交运行、添加到 Agent 对话、合并为组合图和删除同时保留在多选右键菜单中。多选右键菜单不再显示底部的任务节点创建区。

### 节点内快捷操作

节点内容区使用现有视觉语言下的扁平文字按钮，不构造新的图标工具条。

- 空文本/Prompt 节点显示“编辑内容”，复用现有节点编辑入口。
- 空图片节点显示“上传图片”，复用现有替换图片管线。
- 空视频节点显示“上传视频”，接入与图片节点一致的受控文件选择和媒体落盘流程。
- 需要图片或视频输入但尚未绑定素材的任务节点，在现有输入区域直接显示“从画布选择”和“本地上传”。两种入口继续写入现有 `inputBindings` / media input draft。
- 节点已有内容后，只保留现有轻量“编辑”“预览”或“更换”操作，不叠加新的常驻按钮层。
- 按钮必须阻止画布拖拽/选区事件冒泡，并具备键盘焦点、`aria-label`、禁用态和处理中反馈。

节点内快捷按钮只覆盖开始当前节点核心工作的首要动作；选中态顶部工具栏承载右键菜单中可发现的扩展动作，右键菜单继续保留 Agent 引用和删除入口。

### 图片/视频任务节点的比例尺寸联动

比例联动面向带有图片或视频输出能力的操作节点。独立图片/视频素材节点继续优先按实际媒体尺寸拟合，不用配置比例覆盖真实素材比例。

- 参数展示语义层继续识别 `ratio`、`aspectRatio`、`aspect_ratio` 以及被 Schema 声明为画幅的 `size`。
- 用户修改当前模型的画幅字段后，操作节点立即按新比例调整基础卡片宽高。
- 自动调整使用受控宽度和最小/最大高度，保留节点头部、底部状态和内联扩展区所需空间；宽高趋势与目标画幅一致，但不按输出像素创建超大节点。
- 用户随后手动缩放节点时保留手动尺寸，不持续强制锁定比例。
- 用户再次修改画幅参数时，再执行一次自动适配。
- `Auto`、空值、非法值或模型没有画幅字段时保持当前尺寸，不阻断参数保存与任务提交。
- 画幅变化只更新布局尺寸，不改写节点坐标、连线、父组归属或 z-index。

### 现有参数配置面板聚合

保留现有节点配置面板、打开方式、模型选择器、参数预览、运行按钮和高级设置。只改造 `CanvasOperationParameterControls` 的现有常用参数展示：

- 当前工具栏模式不再为比例、分辨率、时长等分别维护独立 Popover。
- 点击现有参数预览区域时，仍使用原有配置面板容器，但一次展示当前模型 Schema 中的全部常用参数。
- 常用参数按任务语义纵向排列：比例宫格、清晰度/分辨率选项、视频时长、生成音频、生成数量，以及当前模型声明的其他常用字段。
- 比例使用带真实宽高趋势的选项宫格；清晰度和数量使用紧凑分段选项；离散时长使用分段选项，连续数值时长使用范围控件与数值回显；布尔型高频参数使用“开启 / 关闭”分段选择。
- 字段、枚举、默认值、最小值和最大值完全来自当前 capability Schema；控件语义由现有 `canvasParameterPresentation` 识别。
- 未识别字段和 Provider 私有配置继续进入现有高级设置折叠区。
- 模型切换后面板原位刷新字段，旧草稿继续经过现有字段筛选、别名兼容和默认值合并逻辑。
- 完整面板、节点内联配置和预设配置继续复用同一参数展示组件，不复制实现。

## 模块边界

- `CanvasNode.tsx`：渲染内容节点空状态文字按钮，并把动作转交现有 node actions；不承载文件落盘或参数解析业务。
- `CanvasOperationMediaInput.tsx` / `CanvasMediaInputConfigurator.tsx`：在缺失输入状态展示“从画布选择 / 本地上传”，复用当前绑定和上传回调。
- `CanvasOperationParameterControls.tsx`：把 toolbar 常用参数从逐项 Popover 调整为现有容器内的聚合展示；panel 变体共享同一字段渲染顺序。
- `CanvasParameterControl.tsx`：补齐连续时长和高频布尔参数的紧凑表现，不改变字段值格式。
- `canvasParameterPresentation.ts`：继续作为比例、分辨率、时长、数量、布尔和常用/高级分类的展示语义事实源。
- `canvasNodeSize.ts`：新增纯函数，将可识别画幅转换为受边界约束的操作节点尺寸。
- `CanvasOperationPanel.tsx`：在现有参数变更回调中识别画幅字段并触发布局更新；继续持有唯一的 `modelParamDraft`。
- 画布 store/API：复用现有节点尺寸更新与持久化动作，不新增独立比例尺寸状态。

`CanvasOperationPanel.tsx` 已接近 3000 行。新增尺寸联动解析和参数聚合逻辑必须放入独立纯函数或小组件，面板文件只保留事件编排和现有回调接线。

## 状态与数据流

### 节点内操作

1. 节点根据类型、现有内容和输入契约判断是否为空或缺失必需输入。
2. 用户点击节点内文字按钮。
3. 组件调用现有编辑、选择、上传或绑定动作。
4. 现有 store/API 更新节点数据或任务输入；节点随状态变化切换为空态或内容态。

### 参数聚合

1. 当前模型 capability Schema 生成 `SchemaField[]`。
2. `canvasParameterPresentation` 将字段分类为常用或高级，并决定控件语义。
3. 现有配置面板一次渲染全部常用字段；每次操作仍回写同一个 `modelParamDraft`。
4. 保存或运行时继续调用现有参数构建、标准化和裁剪流程。

### 比例尺寸联动

1. 参数变更回调收到字段名和值。
2. 展示语义确认该字段是当前 Schema 的画幅字段，而不是按字段名盲猜。
3. 纯尺寸函数解析合法比例，并计算受最小/最大边界约束的节点尺寸。
4. 复用画布节点布局更新动作持久化宽高。
5. 非画幅字段只更新参数草稿，不触发布局写入。

## 错误与边界处理

- 本地文件类型不匹配、读取失败或落盘失败时，复用现有 message 错误反馈并保持节点可重试。
- 任务运行中或节点锁定时，节点内上传、选择和编辑按钮遵循现有禁用规则。
- Schema 没有常用字段时不渲染空的常用参数区，仅保留模型和实际可用的高级设置。
- 枚举过多时允许换行或滚动，不让面板超出视口；窄面板降为单列布局。
- 连续数值缺少可靠最小值/最大值时使用现有数字输入，不擅自生成 Slider 范围。
- 参数别名只用于识别和历史回显，新值仍写入当前 Schema 的规范字段。
- 比例解析失败、`Auto` 或自定义非比例尺寸保持节点当前宽高。
- 自动尺寸更新失败不阻断参数编辑或任务提交；界面保留参数值并允许后续重试。

## 兼容性与迁移

- 不批量迁移历史节点尺寸。
- 历史节点只有在用户再次修改合法画幅参数时触发自动适配。
- 已保存的手动尺寸继续使用；比例不会在每次加载或渲染时强制覆盖。
- 现有任务 payload、Provider 参数、Manifest Schema、草稿恢复和预设存储格式保持不变。
- 当前工作区已有画布节点尺寸和工具栏相关未提交改动，实施时按文件逐块合并，不覆盖用户现有修改。

## 测试策略

### 纯函数测试

- 比例别名识别与合法/非法值解析。
- 16:9、1:1、9:16、21:9 的受边界节点尺寸。
- `Auto`、空值、自定义像素尺寸不触发自动调整。
- 常用/高级字段分类和聚合顺序稳定。

### 组件测试

- 空文本、空图片和空视频节点显示正确文字按钮并调用现有动作。
- 缺失媒体输入的任务节点同时提供“从画布选择 / 本地上传”。
- 现有参数面板一次显示全部常用字段，不再逐项打开独立 Popover。
- 比例、清晰度、时长、音频、数量控件写回正确 Schema 字段。
- 高级设置、模型切换、窄宽度布局和无障碍属性保持可用。

### 集成与回归测试

- 修改画幅后节点尺寸更新一次；手动缩放后保持尺寸；再次修改画幅后重新适配。
- 参数保存、草稿恢复、任务提交 payload 和 Provider 参数裁剪结果不变。
- 图片/视频实际产物节点仍按媒体真实宽高拟合。
- 相关 Vitest、desktop typecheck、lint 和 build 通过；通过本地 Electron 或浏览器自动化核对聚合面板布局和节点内操作。

## 风险控制

- 参数 UI 与 Provider 契约漂移：坚持 Schema 驱动，展示层不新增字段。
- 节点尺寸更新造成画布抖动：只在用户明确修改合法画幅时写入一次，不在 render/effect 中持续校正。
- 文件接入重复实现：节点按钮必须复用现有上传、落盘和绑定管线。
- 大文件继续膨胀：尺寸计算、字段识别和紧凑控件拆入独立模块，`CanvasOperationPanel.tsx` 只接线。
