# 无限画布 UI/UX V4 实施计划

> 状态: 已落地 | 最后核对: 2026-07-14

## 1. 目标与边界

V4 将画布节点、资产卡片、右侧面板、Agent、视频工作台、3D 导演台外框、预设中心与大型弹窗收敛到同一套扁平化产品语言。目标是降低视觉复杂度、提高高频操作效率，并解决弹窗遮挡、快捷键冲突和未保存数据丢失问题。

明确边界：

- 不修改 `Scene3D`、3D 场景数据结构、相机/姿势/道具/灯光逻辑、截图和导出逻辑。
- 3D 导演台只调整顶栏、左右栏、折叠入口、按钮层级和离开保护。
- 不在视觉改造阶段改变节点运行、资产引用、任务产出或放置算法的业务语义。
- 正式实现时不得继续向超大样式文件堆叠新规则；优先拆出节点、弹窗和工作台样式模块。

## 2. 设计方向

### 2.1 视觉语言

- 基底：深灰中性色，最多三层表面色。
- 强调色：低饱和薄荷绿，仅用于主操作、选中、运行和成功。
- 圆角：节点与普通卡片 8–10px，大型弹窗 10–12px。
- 阴影：只用于弹窗、浮层和被拖动节点；普通卡片以边界和底色区分。
- 图标：统一 1.5–1.75px 线性图标；禁止 Emoji；图标按钮仅保留关闭、折叠、播放等难以用短文字表达的操作。
- 按钮：文字按钮优先；描边按钮只用于次要但需要稳定可见的操作；主按钮每个区域最多一个。

### 2.2 节点统一骨架

节点固定为三段：

1. 39px 头部：类型、名称或状态。
2. 内容区：文本摘要、真实预览或统一空态。
3. 35px 底部：元数据与一个上下文操作。

节点尺寸档位：

| 档位  |               建议宽度 | 用途                              |
| ----- | ---------------------: | --------------------------------- |
| S     |              220–240px | 标签、引用、简短文本              |
| M     |              260–300px | 图片、音频、视频、任务、3D 导演台 |
| L     |              420–560px | 分镜脚本、表格、多镜头内容        |
| Group | 内容自适应，最大 720px | 任务多产物容器                    |

默认态不展示成排悬浮图标。选中节点后，仅在底部显示一个高频文字操作；更多操作进入上下文菜单。

### 2.3 占位图系统

以现有 3D 导演台空节点为基准：

- 单个线性类型图标，尺寸 28–32px。
- 主信息一行，次信息一行。
- 使用非常轻的中心径向明暗变化，不使用复杂插画。
- 图片、视频、音频、3D、资产、项目空卡片共用同一布局和间距。
- 有真实缩略图时不叠加装饰插画，只保留格式或状态标签。

### 2.4 运行态

- 外边框使用单条高亮轨迹，1.7–2.0 秒一周。
- 节点内部状态区显示进度、已完成数量和预计时间。
- 禁止整张卡片闪烁或大面积发光。
- 支持暂停动效以及 `prefers-reduced-motion`。

## 3. Agent 与右侧面板

- Agent 左面板不显示头像，发言身份用文字标签区分。
- 上下文条独立放在消息区上方，明确当前读取的节点数量。
- 输入区固定在底部；Enter 发送，Shift+Enter 换行。
- 建议操作使用短文字按钮，最多展示两个，其余收进“更多建议”。
- 右侧面板统一为“详情 / 任务 / 资产 / 项目”四个 Tab，Tab 内容独立滚动，底部操作区固定。

## 4. 3D 导演台实施边界

允许修改：

- `CanvasDirectorStage3DModal` 的外层结构和顶栏信息层级。
- 左右面板的视觉样式、文字按钮、折叠控件和滚动区域。
- 保存状态、快捷键提示和未保存离开确认。

禁止修改：

- `Scene3D.tsx` 及场景渲染树。
- 变换控制、姿势编辑、镜头、灯光、导入模型、截图和导出的行为。
- `Stage3DData` 序列化协议。

实施前为现有 3D 行为补齐回归测试；UI 修改后对同一数据快照验证保存前后结果一致。

## 5. 预设中心

预设中心采用 L 档弹窗：左侧节点类型、中间配置表单、右侧生效范围与状态。保留现有“切换类型不丢草稿、统一保存”的业务逻辑，同时补充：

- 搜索节点类型。
- 清楚区分平台默认、已配置和待保存。
- 明确“只影响后续新建节点”。
- 导入、导出、恢复平台默认。
- 切换类型时先把当前表单写入内存草稿。
- 关闭或取消时检查所有类型草稿与基线是否一致。

## 6. 大型弹窗统一框架

### 6.1 尺寸

| 档位 | 建议尺寸                      | 适用功能                     |
| ---- | ----------------------------- | ---------------------------- |
| M    | 720×640，最大 88vw/88vh       | 选择器、简单设置、确认       |
| L    | 960×720，最大 92vw/92vh       | 节点编辑、生成配置、预设中心 |
| XL   | 视口 92–96%，保留 16px 外边距 | 视频、3D、全景、标注等工作台 |

禁止弹窗内容无限撑高。头部、主体和底部分为三个独立区域，主体内部滚动。

### 6.2 顶部安全区

- macOS 无边框窗口左侧保留交通灯安全区。
- 标题栏拖拽区域与按钮点击区域明确分离，所有按钮设置 `-webkit-app-region: no-drag`。
- 关闭、保存等操作不放在透明遮罩或不可点击的伪元素下方。
- 顶栏高度不低于 56px；点击控件有效尺寸不低于 32px，关键控件不低于 40px。

### 6.3 快捷键作用域

| 操作           | 快捷键                              |
| -------------- | ----------------------------------- |
| 保存           | Cmd/Ctrl + S                        |
| 确认或运行     | Cmd/Ctrl + Enter                    |
| 关闭当前层     | Esc                                 |
| 撤销/重做      | Cmd/Ctrl + Z / Cmd/Ctrl + Shift + Z |
| 查看当前快捷键 | ?                                   |

- 输入框聚焦时不触发画布级删除、缩放、方向键等快捷键。
- Esc 从最上层开始关闭：下拉菜单 → 二级弹窗 → 主弹窗。
- 有关键未保存数据时，Esc 只打开离开确认，不直接关闭。
- 快捷键处理必须集中注册和释放，避免多个弹窗重复响应。

### 6.4 未保存保护

大型工作台引入统一 dirty contract：

```ts
type ModalDirtyGuard = {
  dirty: boolean
  summary: Array<{ label: string; detail: string }>
  save: () => Promise<void>
  discard: () => void
}
```

拦截关闭按钮、Esc、点击遮罩、返回画布、切换项目和应用窗口关闭。确认弹窗提供“继续编辑 / 放弃更改 / 保存并离开”，保存失败时保留现场，不得关闭主弹窗。

## 7. 实施阶段

### Phase 0：行为基线与拆分

- 盘点所有画布大型弹窗和关闭入口。
- 为 3D、视频、节点编辑、图片标注、网格切分、预设中心记录当前快捷键与保存行为。
- 抽出 `CanvasModalFrame`、`CanvasDirtyGuard`、`CanvasShortcutScope`，不改变业务逻辑。

### Phase 1：设计令牌和基础组件

- 新建画布专用 token、线性图标映射、按钮和空态组件。
- 新建 `CanvasNodeFrame`、`CanvasEmptyPreview`、`CanvasStatusLabel`。
- 先迁移 3D 导演台、视频工作台节点，验证与现有数据兼容。

### Phase 2：节点与产物组

- 迁移文本、图片、视频、音频、分镜、任务和资产节点。
- 接入统一运行边框和减少动态效果。
- 完成多产物组的展开、收起、重新排列和防重叠放置。

### Phase 3：面板与资产

- 改造 Agent、右侧四 Tab、资产中心、项目资产中心和项目卡片。
- 验证长名称、空数据、加载、失败、权限受限和离线状态。

### Phase 4：大型弹窗

- 按风险从低到高迁移：选择器 → 预设中心 → 节点编辑 → 视频工作台 → 3D 外框 → 标注与全景。
- 每迁移一个弹窗，验证点击安全区、Tab 顺序、Esc、保存、遮罩和 dirty guard。

### Phase 5：验收与灰度

- 1440×900、1680×1050、1920×1080 三档桌面尺寸视觉回归。
- 键盘全流程、焦点圈、对比度和减少动态效果验收。
- 3D 数据快照、截图、批量导出和姿势撤销重做回归。
- 首批灰度只切换视觉层；出现异常可回退旧样式，不回滚用户数据。

## 8. 验收标准

- 所有节点占位图遵守同一构图，页面内无 Emoji。
- 默认节点不出现超过一个常驻操作按钮。
- 运行态在 100% 和 60% 画布缩放下均可识别。
- 3D 画布内部渲染和核心行为与改造前一致。
- 大型弹窗顶部所有按钮在无边框窗口下可点击。
- 未保存关键数据无法被关闭按钮、Esc、遮罩或返回画布直接丢弃。
- 键盘用户可完成打开、编辑、保存和关闭全流程。

## 9. 2026-07-14 落地记录

本轮已完成以下正式实现：

- 新增 `uiux-v4/` 模块化 LESS 入口，按主题、节点、面板、弹窗、工作台和项目卡片拆分；所有规则使用应用主题变量，小中圆角为 4 / 6 / 9px，不再向 13,000 行旧样式文件追加规则。
- 画布 Agent 保持左侧结构，移除画布会话内全部头像；右侧 Tab、资产管理、项目资产中心、资产详情预览和项目卡片统一为扁平层级。
- 节点收紧默认尺寸：短文本 400×320、长文本 680×560、图片 460×300、视频 500×300、音频 360×280、操作节点 460×420；分镜脚本继续使用 980×620。
- 图片、音频、视频空态统一为“线性图标 + 主信息 + 操作提示”，沿用 3D 导演台节点的安静中心构图；节点运行态使用 1.8 秒周向边框轨迹，并支持 `prefers-reduced-motion`。
- `canvasPlacementEngine` 已通过 `canvasCollisionPlacement` 接入文本、图片、视频、音频、资产插入、菜单操作节点、任务节点和任务产物等核心创建入口；现有顶层节点和组框都参与障碍计算。
- 多产物按最多三列、64px 等距网格整体寻找空位；任务返回多个产物时自动建立真实分组，展开已有操作产物时也自动成组。投影层只内嵌未物化产物，组内产物保持可见。
- 预设中心和 3D 导演台接入统一未保存离开确认；Cmd/Ctrl + Enter 可保存。顶栏拖拽区与按钮区分离，避免无边框窗口隐形区域吞点击。
- 视频工作台和 3D 导演台只调整外部壳层、顶栏和侧栏；`Scene3D.tsx`、3D 数据协议、相机、姿势、道具、灯光、截图和导出核心逻辑未修改。

验证记录：Canvas 目录回归 536 项（63 个测试文件全绿），重点弹窗/3D/放置定向回归 101 项，桌面生产构建通过。仓库原有 `event-mapper.test.ts` 两处 `AgentEvent` 类型错误仍会阻断全量 TypeScript 检查，与本改造无关。
