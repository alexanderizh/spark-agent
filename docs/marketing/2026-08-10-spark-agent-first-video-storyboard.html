视觉与剪辑语言

产品本身是深色桌面软件，视频不再套一层“通用科技蓝”。视觉基调是“夜间控制室 × 影视导演台”，让工程和创作共用同一套光源系统。

色彩：一个主光源，两个工作空间

青色代表可见的执行与连接；紫色代表 Agent / 智能协同；琥珀代表镜头、时间线和导演控制。背景保持 obsidian，避免截图和生成插图互相抢戏。

四条剪辑规则

  • 同一张静态产品截图最长停留 4 秒；功能重点用“局部放大 + 运动路径”表现。
  • 每 20—30 秒必须回到一次真实界面，生成视觉只负责引导，不替代产品证据。
  • 所有过渡都从产品关系出发：连线、节点、光标、时间线、镜头框，不用随机 glitch。
  • 每个镜头只说一个结论；字幕显示用户收益，旁白补充“怎么做到”。

Component / NodeFlow

工作流 / 画布转场

将真实节点截图转成可动画化的 SVG/DOM 层，连接线、折叠、派生和运行状态拥有同一套缓动。

Component / Filmstrip

视频 / 关键帧语法

用胶片条、playhead、时间码和帧卡片呈现视频编辑、深度转换、关键帧抽取，不用夸张的科幻 HUD。

Component / VoiceCue

旁白 / 字幕双轨

每个镜头预留 voice cue、屏幕字幕、屏幕音效和环境声标签；后续可先用临时配音，再替换正式人声。
