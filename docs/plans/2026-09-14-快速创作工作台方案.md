# 快速创作工作台方案

> 状态: 已落地 | 最后核对: 2026-09-22

## 目标

在画布模式新增「快速创作」入口，给不需要先打开具体画布项目的用户提供统一的多媒体创作台。首批覆盖图片生成、图片反推和视频生成，并支持已配置 Provider/模型、提示词快捷使用、输入素材、任务状态和结果复用。

## 设计边界

- 页面沿用 Spark 现有扁平深色工作台：以分割线、文字层级和品牌强调色组织信息，不复制参考图的卡片堆叠布局。
- 图片/视频调用复用 `canvas:task:create-media`，图片反推复用 `canvas:task:generate-text`；不新增重复的 Provider 请求协议和密钥通道。
- 模型清单和参数字段由现有 MediaModelManifest/Contract V2 驱动。图片有无输入素材时分别选择生成或编辑能力；视频支持纯文本、首帧/参考图和视频编辑能力的兼容路由。
- 原生选择的本地输入通过 `file:prepare-media-input` 复制到应用管理的安全媒体目录；剪贴板图片通过 `file:save-pasted-image` 落盘后再进入输入区。任务记录仅保存安全文件引用，不把大型 data URL 写入 localStorage。
- 快速创作历史索引保存于 `spark-canvas:quick-create-tasks:v1`，最多保留 60 条。删除任务时仅清理画布媒体目录内的任务产物和 `quick-create-inputs` 下的任务专属输入拷贝；共享粘贴素材、用户原始文件与白名单外路径不删除。
- 表单选择保存在 `spark-canvas:quick-create-preferences:v1`，按模式 / operation / 模型 / capability 隔离参数，重新进入页面时恢复上次选择；自定义尺寸与比例历史复用画布的 `spark-canvas:parameter-history:v1`，保证两个入口看到同一组选项。

## 交互结构

1. 侧栏「画布」模式下提供「快速创作」入口。
2. 页面采用左创作表单、右结果/历史结构，左栏最大宽度 520px，右侧内容区铺满剩余空间；结果区可切换「创作结果 / 创作历史」，顶部保留进入任务管理的快捷入口，窄窗口下切换为上下布局。容器以灰阶背景、紧凑间距和文字层级组织，不使用边框盒子、页面级渐变、装饰性空状态或营销卡片。
3. 创作表单提供图片生成 / 图片反推 / 视频生成模式，使用紧凑分段切换器；三种模式均支持选择、粘贴和拖入外部素材，反推模式同时支持提示词文字输入。表单按创作顺序组织为「参考素材 → 提示词 → 参数 → 生成」，参考素材区仅保留紧凑缩略图、数量和添加入口。提示词库从输入框右上角打开独立弹窗，以封面卡片展示全部可用提示词；已提交任务可在任务操作区存入提示词库，并自动使用第一张图片产物作为封面。
4. 输出区展示当前任务结果，支持多图缩略导航、输入图 / 输出图对比；仅存在输入图片时显示对比入口。任务详情中的图片和视频使用独立弹层查看，不改变创作结果区当前内容。公用 `MediaArtifactViewer` 提供翻页、工具栏、滚轮缩放、拖拽平移、复制、下载、下载目录记忆和打开所在文件夹能力。
5. 参数候选仍由画布的 `canvasParameterPresentation` 与 `canvasParameterHistory` 提供，快速创作只为高频字段提供更合适的交互：质量使用下拉选择，数量使用受 schema 范围约束的减号 / 可编辑数字 / 加号，尺寸先展示前五项，剩余枚举、自定义输入和缓存值收纳在「更多配置」中。所有值最终仍交给画布同源的参数字段和历史逻辑，不在快速创作内另维护一套选项；高级参数折叠并摘要当前值。
6. 页面配色全部使用应用主题 token（primary/bg/text/divider），左侧表单与右侧输出区均使用灰阶背景分层，输入控件采用无边框的差异底色；明暗双主题一致，不内置页面级硬编码色值。图标仅使用语义化线性图标，不使用 emoji 或 sparkle/wand 等装饰性图标。
7. 任务请求与任务运行状态分离，允许连续提交；任务通过 clientTaskId 关联事件，任务管理 Tab 可展开查看详情、复制提示词，并缓存列表/卡片显示状态。成功、失败、取消任务均可重试，任意状态任务均可复用；用户修改表单或重置时清空右侧旧结果焦点，但不删除历史记录。
8. 图片与任务支持右键菜单：任务历史的卡片封面、列表行、详情弹层大图、产物查看弹层（`MediaArtifactViewer` 舞台），以及创作结果的全屏大图灯箱，都能右键唤起同一套菜单。产物组提供查看大图 / 查看视频、复制图片、另存为、打开所在文件夹；任务组提供查看详情、复制提示词、复用配置、重试、存入提示词库，末项「删除任务」沿用既有确认弹窗（只清理任务专属输入拷贝与画布媒体目录内产物）。菜单用公用 `ContextMenu`（`contextMenuModel` + 浮层）渲染在 body portal 上，靠近窗口右下角时按实际尺寸向内收敛；菜单自己维护高亮项、不抢焦点，↑/↓ 移动高亮、Enter 执行、Esc 只关菜单；菜单打开期间方向键归菜单，下层查看器不再翻页或缩放。
9. 页面默认嵌入应用主体窗口；头部右侧提供「在独立窗口中打开」图标按钮，点击后打开并聚焦复用的快速创作独立窗口。独立窗口复用同一套任务记录、流式任务事件和主题设置，窗口关闭后再次点击可重新创建。

## 运行与日志

任务请求继续通过主进程既有 `canvas:task` 生命周期日志记录，不在渲染端打印 API Key 或完整敏感请求。页面只消费 `stream:canvas:media-task` 与 `stream:canvas:text-task` 的终态更新。

## 验收标准

- 侧栏可以稳定进入快速创作，且不影响原有画布项目、提示词库和渠道视频任务入口。
- 三种模式在没有对应模型时给出明确空状态；有模型时可提交真实任务并在记录区显示流式终态。
- 图片反推强制单图并支持补充文字提示词；三种模式均可选择、粘贴或拖入受支持的图片/视频素材，失败有就近反馈。
- 点击输出图片可打开统一大图预览组件；多图输出支持工作台内翻页和预览组件内键盘翻页，存在输入图时可切换输入/输出对比，任务详情查看不改变创作结果区。
- 模式、模型、视觉理解模型和参数选择重新进入页面后按上次选择恢复；页面文案不展示内部消耗点或计费概念。
- 自定义尺寸在任务被 Provider 接受后进入当前模型作用域的已保存列表，可再次选择或删除；尺寸控件提供预设矩形、更多尺寸下拉与自定义输入三层选择，比例按钮在半宽容器内也不得出现文字竖排或溢出；连续提交时前一个请求的返回不会覆盖用户正在编辑的新提示词。
- 任务刷新或重新进入页面后，历史索引及列表/卡片显示状态仍可读取；删除任务只清理任务专属输入拷贝与画布媒体目录内产物，不删除共享素材或用户原始文件。
- 任务历史的卡片、列表行、详情弹层与产物查看弹层都可右键唤起菜单：右键图片可直接复制图片 / 另存为 / 打开所在文件夹，右键任务可直接删除任务；菜单不溢出窗口，Esc 只关菜单，不会同时关掉下层弹层或全屏灯箱。
- 头部独立窗口按钮在主体窗口可见且可点击；点击后打开独立快速创作窗口，重复点击复用并聚焦已有窗口，独立窗口在 macOS / Windows / Linux 均保留可用的窗口 chrome。
- 已完成目标 lint、聚焦测试和生产构建；全量 renderer strict typecheck 当前受工作区已有的 `userMenuItems.tsx:137` 类型错误阻塞。真实桌面界面验证需待 Computer Use capability 恢复后补做，当前未用旧安装包替代。
