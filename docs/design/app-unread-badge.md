# 桌面应用未读会话徽标

> 状态: 已落地 | 最后核对: 2026-07-31

## 目标与口径

桌面系统徽标复用会话侧栏蓝点的唯一数据源：`unreviewedCompletedSessions`。计数按会话去重，不统计消息条数，也暂不叠加权限或计划审批。

当后台会话完成时，该会话进入未读集合；用户进入对应会话后，会话从集合移除，系统徽标同步更新。计数归零时清除系统徽标。

## 平台行为

- macOS：Dock 显示未读会话数量，超过 99 显示 `99+`。
- Linux：调用 Electron launcher badge API 显示未读会话数量；不支持该能力的桌面环境保留托盘提示作为降级。
- Windows：任务栏只显示或清除红点，不在角标中绘制数字；无障碍描述仍包含实际未读数。
- 所有平台：托盘 tooltip 在有未读时显示未读会话数，归零后恢复为 `SparkWork`。

## 实现链路

1. `SessionSidebarContext` 监听未读集合大小，并通过 `app:set-unread-count` IPC 同步主进程。
2. IPC 使用独立协议模块进行类型约束和 Zod 入参校验，计数范围为 0～9999。
3. `AppUnreadBadgeService` 负责归一化计数并按运行平台调用 Electron API。

## 验证边界

平台徽标 API 必须在对应操作系统的打包应用中做最终视觉验收。单元测试覆盖计数归一化、macOS 数字格式、Linux 数字调用、Windows 红点显示与清除，以及托盘提示文案。
