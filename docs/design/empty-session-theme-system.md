# 空会话主题系统

> 状态: 已落地 | 最后核对: 2026-08-13

## 目标

空会话页从单一居中布局升级为可切换的品牌化工作台，同时保持输入框、运行模式、模型、项目、分支和发送行为完全复用。用户可以从左下角用户菜单的「Theme → 会话主题」即时切换，选择结果随外观设置持久化。

## 内置主题

| ID          | 名称       | 视觉方向                         |
| ----------- | ---------- | -------------------------------- |
| `none`      | 不应用主题 | 恢复主题系统上线前的经典空会话页 |
| `celestial` | 星图工作台 | 星轨、通透卡片、轻盈科技感       |
| `studio`    | 灵感工作桌 | 温暖纸感、编辑拼贴、亲和创作感   |
| `midnight`  | 午夜星港   | 低眩光深色、夜间专注、克制光效   |
| `geometry`  | 几何引擎   | 几何构成、高对比品牌色、年轻张力 |

## 交互与持久化

- 全局浅色、深色、跟随系统仍由 `theme` 控制。
- 会话主题由独立字段 `emptyHeroTheme` 控制，只影响空会话视觉，不改变消息页，并随全局浅色、深色模式切换对应的表面和文字变量。
- 选择 `none` 时不挂载 `data-empty-theme`，欢迎文案、快捷卡片、输入框与应用背景全部回到经典样式。
- 单 Agent 空会话的欢迎标题末尾提供轻量的「主题 · 当前主题」快捷选择器；入口在所有内置主题中保持同一位置，颜色与弹层表面继承当前主题变量。
- 选择写入 `spark-settings-appearance`，并通过现有 `settings:set` IPC 同步到外观设置。
- 新用户及无有效主题配置时默认使用 `none`；无效或旧版本主题 ID 也自动回退到 `none`。
- 快捷操作保持真实能力入口；主题模式宽屏每页四张、中等窗口两张，经典模式宽屏每页三张，窄屏均为一张，并沿用自动轮换与悬停暂停。
- 欢迎区、输入框和会话参数栏共享同一套局部表面与文字变量；参数弹窗属于最高交互层，不会再被 Banner 或快捷卡片遮挡。
- 各主题保留配色、背景纹理和插画语言，但标题字号、卡片高度、圆角、阴影与信息密度统一收敛，以便和应用侧边栏保持一致。
- Banner 文案、快捷卡片组与输入区域共享相同的左右边界；所有会话主题均不再展示宠物装饰。
- 空会话的完整主题背景由应用 shell 统一绘制，侧栏外边距、侧栏与内容区之间的 gutter、内容区共享同一张连续背景，避免分层底色形成隔离缝隙。
- 侧栏默认使用悬浮毛玻璃材质：开启背景模糊时轻微透出当前主题底色，关闭模糊或系统要求降低透明度时回退为不透明面板。

## 组件边界

- `emptyHeroThemes.ts`：主题清单、文案、菜单预览和类型校验。
- `ChatHero.tsx`：Banner、快捷卡片和主题结构。
- `ChatEmptyThemes.less`：四套主题背景、卡片、输入框表面和响应式规则。
- `AppContext.tsx`：主题选择的初始化、校验与持久化。
- `App.tsx`：用户菜单中的主题选择入口。

## 可访问性与响应式

- 主题卡片使用原生 `button`，保留键盘聚焦和可读文本。
- `prefers-reduced-motion` 下关闭新增过渡。
- 小于 720px 时隐藏抽象 Banner 装饰，卡片改为单列，空会话区域允许纵向滚动。
- 矮窗口会压缩 Banner、卡片和间距，保留输入框在首屏内。

## 扩展约束

新增主题时必须同时补齐主题配置、视觉变量和菜单预览，并保持主题样式只作用于带 `data-empty-theme` 的空会话容器。不得复制 Composer 业务逻辑或为单个主题创建独立输入框实现。
