# 团队会话运行态与活动日志

> 状态: 已落地 | 最后核对: 2026-08-13

团队会话的 `running` 表示 Host 主循环、启动中的 turn 或任一成员 dispatch 仍在执行。`TeamDispatchService` 在成员 dispatch 开始和结束时刷新会话队列快照；持久化会话摘要、侧栏状态、Composer 停止按钮和运行 Agent 标签共同使用这份会话级运行态。Host 的终态事件不能覆盖仍为 running 的队列快照，历史重放也会保留尚未收尾的成员活动，避免切换会话后错误显示为空闲。

团队检查器提供“显示思考与执行日志”开关，默认关闭并保存在本机。关闭时会话时间线保持结果优先，只展示 Host/成员正文和协作结果；打开后展示 Host 与成员的思考、命令、工具和带 diff 的文件变更。成员日志继续携带 dispatch 与成员归属，渲染在对应成员气泡内，并复用标准活动日志的分组和折叠交互。

显式停止、清空或删除会话仍会取消 Host 和该会话的全部成员 dispatch；取消路径不等待普通终态竞争即可把会话恢复为空闲。
