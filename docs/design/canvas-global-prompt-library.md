# 通用提示词库

> 状态: 已落地 | 最后核对: 2026-08-08

提示词库是跨画布项目复用的全局数据，不属于任何单个 Canvas 项目。用户自建提示词、分类、标签和封面统一存储在全局设置 `prompt-library/data` 中；管理页即使没有创建画布项目也可以浏览、创建、编辑和复制提示词。

旧版本保存在项目资产中的 `prompt_library` 资产会在首次加载时从所有已有项目迁移到全局库，迁移使用稳定的 `legacy:<assetId>` 标识，避免重复导入。迁移完成后，后续编辑和分类变更只写入全局库。

画布内提示词面板同时展示全局提示词与内置电影提示词。全局提示词在没有画布目标时复制到剪贴板；有画布目标时仍可直接应用到当前画布。
