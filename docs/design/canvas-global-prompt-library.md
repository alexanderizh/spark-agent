# 通用提示词库

> 状态: 已落地 | 最后核对: 2026-08-23

提示词库是跨画布项目复用的全局数据，不属于任何单个 Canvas 项目。用户自建提示词、分类、标签和封面统一存储在全局设置 `prompt-library/data` 中；管理页即使没有创建画布项目也可以浏览、创建、编辑和复制提示词。Ctrl/Cmd+T 快捷弹窗提供“全局 / 项目”两个来源，其中“全局”与管理页的用户提示词总集合一致：包含全局存储提示词和所有活动画布项目保存的提示词；“项目”单独展示当前画布项目的提示词。

旧版本保存在项目资产中的 `prompt_library` 资产会在项目删除前转存到全局库，迁移使用稳定的 `legacy:<projectId>:<assetId>` 标识，避免重复导入。项目删除前会把 `safe-file://` 参考图读取为 data URL 后再保存；参考图无法读取时中止删除，避免提示词被保留但参考图丢失。已有 `legacy:*` 条目会正常展示，不再被快捷弹窗或管理页过滤。

画布内普通提示词面板仍可展示全局提示词、项目提示词与内置电影提示词；Ctrl/Cmd+T 弹窗只展示用户保存的全局和项目提示词，并支持按添加时间最新/最早排序，且不限制结果数量。全局提示词在没有画布目标时复制到剪贴板，有画布目标时仍可直接应用到当前画布。
