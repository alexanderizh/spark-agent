# Assistant Turn 完成态自动折叠

> 状态: 已落地 | 最后核对: 2026-09-02

## 目标

主会话中的每条 Assistant turn 在整轮真实结束后自动折叠。折叠态只渲染该轮最终答复正文，过程性正文、思考、工具日志、团队派发记录和文件变更仍保留在消息数据中，用户展开后可完整查看。

## 完成边界

自动折叠只由 Renderer 归一化后的 `UIMessage.status === 'completed'` 触发。`assistant_message.isFinal` 只负责标记最终答复块，不负责触发折叠，因此最终正文、单个工具结果、思考块结束、电脑操作停止等局部信号不会提前收起正在执行的 turn。

Claude 与 Codex 都先把各自 SDK 事件归约为同一 `UIMessage` 状态，但最终事件语义不同：Claude 的 result 文本是最终答复，result 覆盖到的正文段会明确标记为最终答复；Codex 的 final 文本可能聚合整轮全部 Assistant 正文，因此只将末段标记为锚点。Renderer 使用统一投影：从锚点向前保留最近一次工具/过程日志之后连续出现的同类正文；没有过程边界时只信任明确标记的正文。这样 Claude 的完整总结不会被截成最后一句，Codex 也不会把工具前的过程说明误当总结。旧历史缺少最终答复标记时复用末尾正文规则；整轮没有工具/过程日志时，只保留末尾连续正文段。

时间线不可见块不参与正文连续性判定：`quick_replies`（suggest_replies 工具产物，仅在输入框上方展示）与被时间线隐藏的 `present_files` 工具调用在正文流中不产生任何可见内容，既不算过程边界也不切断总结正文。Claude 的 result 只携带最后一条 assistant message 文本，当正文主体位于 suggest_replies 等 UI 附着工具之前时，mapper 会把最终答复标记向前扩展到仅被附着块分隔的连续正文段（Codex 不扩展），保证折叠态保留完整的最终答复而非只剩最后一句。

Spark助手的内置提示词同时约束最终交付：由于每轮完成后界面默认折叠中间过程，最终回复块必须包含可独立阅读的完整答复，包括关键结论、实际完成内容、验证结果，以及必要的风险或下一步；不能依赖折叠后的中间正文补全信息。

## 展示规则

- `streaming`、`error`、`cancelled` 不自动折叠。
- 待审批计划、待确认 Goal 契约、待回答问题、权限请求、警告/错误信号和仍在运行的工具或子任务保持展开。
- 已完成且存在最终正文时显示一个整轮折叠入口；默认收起，最近一次工具/过程日志之后的单段或多段末尾总结正文均完整展示，点击后恢复该轮全部原始 blocks，工具前的过程正文不进入折叠摘要。
- 折叠态保留自包含的产物展示块：含可见交付文件（文档/媒体）的 `presented_files`、渲染成功的 `html_block` / `diagram_block`，以及面向交付结果的汇总卡片（含文件明细的 `turn_file_summary`、有内容的 `validation_suggestion`、有预览地址的 `application_snapshot`），顺序为最终正文在前、产物块按原时间线顺序跟随。无可展示内容的产物块、渲染失败的 HTML/图表不保留；上下文压缩、重试轨迹、checkpoint 等系统过程提示仍随折叠收起。
- 历史 Assistant turn 的最终正文不再套用旧的 `500px` 高度截断，折叠态可直接阅读完整总结，无需再点击“展开全部”。
- 折叠只改变 Renderer 投影，不删除或改写消息、事件、复制/引用数据和历史审计内容。
- 没有正文的产物型或状态型消息不强行折叠，避免隐藏唯一可见结果。

## 团队模式

团队消息继续保存在 Host assistant turn 的统一时间线中。成员 dispatch 为 `pending` / `working`、成员正文仍在流式输出或成员工具仍在运行时，即使 Host 已收到局部终态也不折叠。

整轮完成后优先保留 Host 的最终答复；直接 `@` 成员等没有 Host 最终答复的路径保留最后一个成员最终答复。展开后恢复 Host、成员、协作消息和执行日志的原有时间顺序，团队日志可见性设置继续生效。

## 验证

聚焦测试覆盖统一终态门控、最终正文投影、折叠态保留产物展示块与交付汇总卡片（含无可展示内容与渲染失败块的过滤）、旧历史回退、历史总结不再二次截断、审批/问题/警告保护、Codex 多段聚合去重、Claude 跨 quick_replies 的 final 扩展与 Codex 不扩展对照、时间线不可见块不切断正文、团队成员最终答复和运行中 dispatch 防提前折叠。Desktop strict typecheck 作为跨组件类型兼容门禁。
