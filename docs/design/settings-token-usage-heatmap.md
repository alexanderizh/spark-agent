# 设置通用页 Token 用量热力图

> 状态: 已落地 | 最后核对: 2026-08-10

## 目标

在「设置 → 通用」页提供一个轻量的 Token 用量概览，让用户不离开常用设置即可观察近期使用活跃度。

## 当前行为

- 数据来自本地 `usage_ledger`，通过 `usage:get-by-date-range` 按日期读取。
- 支持最近 12 周、6 个月和 1 年三个范围；日期按 UTC 日边界查询，与 SQLite 的日聚合保持一致。
- 每日热力值为输入 Token、输出 Token 和推理输出 Token 之和；空日期仍保留在网格中。
- 单元格悬停/键盘聚焦时显示 Tooltip，并通过提亮、轻微放大提供反馈；无障碍标签和原生 title 同时显示日期、Token 数量和请求次数。
- 颜色分为无用量和四档强度，支持深色主题、窄屏横向滚动、加载中、空数据和重试状态。
- 卡片固定占满设置内容列，单元格和网格间距保持固定；较长时间范围只在卡片内部横向滚动。

## 实现边界

热力图组件位于 `apps/desktop/src/renderer/design/views/UsageHeatmap.tsx`，日期网格与强度计算位于同目录的 `usageHeatmap.utils.ts`。现有「设置 → 用量统计」页面保持不变。
