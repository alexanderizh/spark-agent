# 画布分镜编辑器设计

> 状态: 已落地 | 最后核对: 2026-07-21

## 背景

分镜脚本拥有三十余个制作字段。把所有字段横向铺在表格中会造成列宽不足、横向滚动路径过长、长文本行高失控，并且镜头管理与字段编辑混在同一视觉层级中，不适合作为专业制作工具交付。

## 设计目标

- 分镜编辑从通用文本节点表格中独立出来，形成专用工作台。
- 同一时刻聚焦一个镜头，长文本拥有完整编辑宽度。
- 镜头序列管理始终可见，支持添加、选择、复制、删除、排序。
- 覆盖 `ParsedShotRow` 完整制作契约，不因界面精简而丢失字段。
- 复用现有解析、序列化和保存协议，不迁移历史分镜数据。

## 信息架构

编辑器采用 master-detail 布局：

- 左侧镜头序列：显示镜号、标题、画面摘要、景别、运镜和时长，并承载添加与排序操作。
- 右侧镜头 Inspector：顶部显示当前镜头身份和复制/删除操作，下方按制作阶段切换配置域。
- 画面设计：镜头基础信息、场次、场景、构图、画面动作和首尾帧。
- 摄影光色：焦距、光圈、ISO、综合镜头参数、光照、色调和氛围。
- 角色表演：角色选择、角色参考、造型、站位调度、表演、动作节拍和连续性。
- 对白声音：对白、旁白、声音设计和转场剪辑。
- 生成控制：生成提示词与反向提示词。

## 交互规则

- 新镜头插入当前镜头之后，并自动选中。
- 复制、删除、上移、下移后统一重排镜号，避免结构操作产生重复编号。
- 角色既可从项目角色资产中选择，也可手动输入名称。
- 多行字段按内容自动增长，在合理上限后内部滚动，编辑器本身只纵向滚动。
- 全屏与内联入口复用同一个编辑器组件，不再维护两套表格实现。
- 预览、任务配置和分镜编辑共享同一个工作台全屏状态；全屏覆盖整个渲染窗口并解除内部高度上限，切换预览/编辑不会退出，`Esc` 可随时返回内联布局。
- 小屏幕下镜头序列切换为横向卡片轨道，Inspector 字段改为单列。

## 数据兼容

编辑器只修改内存中的 `ParsedShotRow[]`。保存时继续通过 `formatStoryboardRowsAsMarkdown()` 写回节点文本，打开时继续通过 `resolveStoryboardRowsForEditing()` 解析现有 JSON、Markdown 和已物化分镜引用。

本次改造不新增节点类型、不修改 IPC、不改变任务和资产数据结构。
