# 会话侧面板视觉规范

> 状态: 已落地 | 最后核对: 2026-09-11

配置面板和会话检查器共用 `SessionPanelDesign.less`，样式限定在 `session-panel` 内，沿用应用明暗主题色。其他终端、预览和审查面板不受影响。

- 两个面板以功能模块作为主卡片层级；面板内边距、卡片间距和卡片内边距使用全局 `--pad-md`。卡片及输入控件圆角使用 `--r-sm`，控件高度使用 `--row-h`，跟随应用密度与圆角设置。
- 每条环境变量使用无边框、无阴影的主题浅色背景块表达独立项，保持轻量层级；字段仍是扁平排列，聚焦时仅改变背景反馈。统计区和提示词区不增加二级卡片。
- 环境变量保留键名、值、说明的持续可见标签。面板宽度小于 400px 时纵向排列；更宽时键和值并排、说明独占一行。删除操作固定在该变量右上方。
- 项目和会话分别显示作用范围与变量数量，复制、导入和保存集中在各自区块末尾。
- 环境变量继续失焦自动保存、删除立即保存，并保留手动保存入口。提示词仍需显式保存。
- 配置折叠使用原生按钮，提供展开状态、键盘操作及焦点轮廓。提示词具有可访问名称。
- 检查器共用分区容器，对用量数字、键值信息和空状态统一留白与排版，保留原有数据来源及计算方式。

验证包含配置保存、剪贴板导入导出、折叠后草稿保留、检查器工具函数和已有折叠组件测试。此次修改不涉及运行时或 IPC 协议。
