# 画布 Agent 全能侧面板

> 状态: 已落地 | 最后核对: 2026-08-24

## 目标

画布 Agent 侧面板应当是主 Agent 会话能力在无限画布场景下的完整投影，而不是只支持文字发送的简化聊天框。用户可以把画布上下文、产物和本地文件直接交给 Agent；Agent 请求权限时在当前侧面板完成审批；会话配置和执行状态始终与底层 Session 同源。

## 架构原则

- 复用 `SessionAttachment`、`session:create/update/submit-turn` 和权限审批 IPC，不创建画布专属会话协议。
- 画布节点引用用于定位和工具上下文；可读取的本地产物作为附件，两者语义分离。
- 权限模式以 Session 为权威。切换 Agent、Provider 或 adapter 时使用共享选项校验，不把 Claude 模式带到 Codex，反之亦然。
- 审批请求必须按 `sessionId` 路由；后台会话的请求不能出现在当前画布会话。
- 超过 3000 行的集成文件只做薄接线；拖拽载荷、附件解析和权限选项等逻辑放入独立模块并以纯函数测试覆盖。

## 第一阶段能力

### 产物拖入会话

操作节点的图片、视频、音频等本地产物，以及资产管理中的本地资产，使用版本化 MIME 载荷进入拖拽。侧面板把载荷解析为 `SessionAttachment`，在发送前以附件条展示，可移除并与文字一起发送。

只有能够解析为本地绝对路径的产物可以成为文件附件。仅有远程 URL 的产物不会被静默丢弃，侧面板应提示用户先下载或物化到本地。

### 权限与审批

侧面板提供适配当前 runtime 的权限模式：Claude 与 Codex 使用共享权限选项目录。新建会话写入所选模式，已有会话切换后通过 `session:update` 持久化，每轮提交再次携带当前模式作为运行权威。

当当前会话收到 `stream:permission:approval-request` 时，输入区上方展示风险、工具和参数摘要，并支持允许一次、会话允许、拒绝、会话拒绝。`stream:permission:approval-resolved` 到达后只收起匹配的请求。

### 交互不变量

- 拖拽附件不能触发画布 pan、选区或节点移动。
- 产物无本地路径时不制造无效附件。
- 会话运行中禁止切换 Agent、模型、Skills 和权限模式。
- 切换项目、会话或 adapter 后，权限选择必须恢复到对应 Session 或兼容默认值。
- 审批卡永远只响应当前会话、当前 requestId。

## 后续阶段

- 支持把多运行/多产物集合以结构化引用加入会话，而非只发送文件。
- 对齐主会话的计划审批、目标预算、用户问题与上下文用量展示。
- 将 Agent 工具结果、画布任务和节点运行历史建立双向定位与重试入口。
- 以画布 acceptance runner 持续覆盖拖拽、任务状态、持久化、画廊、权限与 Agent 会话的端到端场景。

## 落地验证

- 拖拽附件、远程产物拒绝、审批事件路由和权限选择共 6 个聚焦测试文件通过。
- Renderer 与 Main strict TypeScript、目标 ESLint、Prettier 和桌面生产构建通过。
- Electron 真实流程覆盖权限模式切换、拖入附件、附件展示与移除。
