# 画布视频工作台

> 状态: 实施中 | 最后核对: 2026-08-25

## 创建与连线

- 底部工具栏和画布空白处右键菜单都可以创建视频工作台。
- 从节点输出柄拖线到空白处后，可以在右键创建菜单中直接创建视频工作台并完成连接。
- 指向视频工作台的人工连线使用 `used_as_input`，供上游资源自动收集使用；`generated` 仅由任务产物回写显式创建，不能由人工连线推断。
- 普通视频节点和视频任务节点中的产物预览，双击都打开对应节点的画布编辑面板；第二次点击阶段即拦截视频元素的原生全屏行为，避免先进入全屏播放再弹出编辑面板。需要进入工作台时使用节点菜单中的“视频编辑”显式入口，视频工作台节点自身仍可双击进入工作台。

## 画布自研视频播放器

- 普通视频节点、视频任务节点的产物预览和视频节点编辑面板共用 `CanvasVideoPlayer`，不再直接暴露浏览器原生 `controls`。
- 播放器按容器宽度提供 mini / standard / panel 三档：迷你档显示中央播放键、常驻进度指示和时长；标准档提供播放、时间、进度、静音和全屏；面板档增加逐帧、音量、倍速和循环。
- 面板档时间码支持一位小数显示；逐帧以 30fps 的默认帧间隔步进，后续可替换为真实帧率元数据。
- 控制条和中央播放按钮使用 `nodrag`、`nopan`、`nowheel` 接管交互，视频画面仍保留节点选择、拖拽、画布平移和双击编辑链路；控制区双击不会误触发节点编辑。
- 播放中连续 2.5 秒无操作时隐藏浮层控件，悬停、聚焦或再次操作时恢复；全屏由播放器外壳管理，不启用画中画和远程播放入口。

## 画布视频节点尺寸

- 普通视频节点、视频任务节点和展开后的任务产物统一使用视频原始宽高比，不再继承历史默认高度或固定媒体高度上限。
- 新建/拖入视频时优先读取资产宽高；Provider 未返回宽高时读取视频元数据，并把有效宽高写入资产。旧节点或旧任务产物在浏览器加载视频元数据后会回填宽高并自动恢复比例。
- 视频任务在运行前使用模型参数中的 `aspectRatio`、`aspect_ratio`、`ratio` 或 `size` 预估比例；完成后以当前主产物的真实宽高为准。任务状态变化、切换运行记录或主产物时会立即重算，竖屏切到横屏也允许节点高度缩小。
- 视频节点手动缩放时锁定媒体比例，避免用户再次写入拉伸尺寸；任务多运行导航只在确有多轮运行时占用固定高度。

## 工作台窗口

- 视频工作台使用覆盖应用内容区的全屏布局，不保留传统弹窗的四周留白与圆角。
- macOS 下顶栏继续为窗口红绿灯保留左侧安全区，关闭按钮和资源入口保持可操作。

## 关键帧提取与导入

- 均匀采样的采样间隔最低为 0.2 秒；历史工作台配置低于该值时按 0.2 秒读取，IPC 与 FFmpeg 边界也执行同样的下限保护。
- 批量导入关键帧时，以一个组节点承载所有图片节点（单张关键帧仍直接导入图片节点）。组内按关键帧在原视频中的时间从左到右、从上到下排列，并将源视频工作台节点连接到组节点。

## 资源选择

- 本机文件选择支持一次导入多张图片、多个视频和多个音频文件。
- “从画布选择资源”支持图片、视频和音频，并提供多选、类型筛选、标题/文件名搜索和当前结果全选。
- 候选资源使用单列纵向滚动列表；图片和视频显示缩略图，音频显示类型信息，悬停或键盘聚焦时在右侧显示对应预览。
- 顶部“添加资源”菜单使用受控宽度；画布主视频选择通过独立的单选资源面板完成，不再把所有视频文件名直接展开到菜单中。

## 上游收集

“按上级连线收集”只读取指向当前工作台的 `used_as_input` 边。每个上游节点优先选择首个视频产物，没有视频时回退到首个图片产物。
为兼容旧版本，目标为视频工作台且带 `metadata.manual` 的遗留 `generated` 边也按上游输入读取，并且不会再触发节点折叠。

## 多轨时间线

- 源视频首次打开时迁入资源面板和默认主视频轨；工作台底部统一渲染主视频、叠加和音频轨，不再并存两套时间线。
- 图片、视频和音频资源可以从右侧资源面板拖到兼容轨道的指定时间，也可以点击加入默认轨道；操作成功后立即选中新片段并切换主预览。
- 标尺、片段带和播放头位于同一个横向滚动视口，共享 `时间秒数 × pixelsPerSecond` 坐标；片段宽度严格按实际播放时长计算，缩放只改变内部时间坐标和内容宽度。
- 主视频轨禁止片段重叠；开启磁吸主轨时，单片段拖动按插入位置重新排序并连续排布，叠加和音频轨仍保留绝对时间。片段支持移动、双边裁剪、分割、复制、删除和修饰键多选，批量操作由单条 command 原子提交。
- 轨道支持重命名、排序、折叠、锁定、显隐、静音和独奏；红色播放头支持指针拖动与键盘微调。播放控制和时间码统一保留在预览区左侧蓝色播放器，时间线不再重复展示第二套播放入口。
- 现有关键帧、单项剪辑和产物面板暂时通过兼容视图消费主视频轨；真实多图层合成预览与导出尚未落地。

## 响应式与可访问性

- 右侧面板宽度使用 `clamp(300px, 30vw, 360px)`，预览区保留剩余空间；800px 窗口仍保持 300px 资源面板和 500px 预览/时间线区域。
- 多轨工具栏使用局部容器查询：761–1040px 把有图标的主操作收为图标模式，760px 以下换为上下两行，520px 以下进一步压缩开关和尺寸；所有模式都保留完整可访问名称。
- 主预览宽度不超过 560px 时，分段复制、添加到画布、替换和删除收为图标按钮，避免时间码和操作文字纵向堆叠。
- 时间线、片段、裁剪句柄、播放器和资源卡操作均提供清晰的键盘焦点状态；hover 才出现的资源操作在 `focus-within` 时同样可见，并遵循系统的 reduced-motion 设置。
- 1310×800、1024×768、800×600 三档 Electron 实测均无页面横向溢出、时间线控件重叠或播放器控件重叠；拖入 6 秒视频后新片段立即选中，主预览媒体元数据加载完成。

## 多轨 V2 实施边界

- 工作台编辑与持久化已切换为 V2；旧 V1 数据在打开时先通过纯函数迁移，发生编辑或缺失源轨的必要初始化后才写入 V2。未知未来版本进入只读保护，禁止覆盖保存。
- V2 模型位于 `videoWorkbench/model/`，包含版本化项目模型、V1 纯迁移、严格解析、共享时间语义、轨道规则、吸附、command reducer、有界历史和资源元数据回填。
- 底部已使用独立 `timeline/` 模块渲染多轨时间线。主视频、叠加和音频轨支持轨道头控制、原地重命名、拖拽/键盘排序、绝对时间拖放、双边裁剪、分割、复制、删除、吸附、锁定、折叠、显隐、静音与独奏；片段支持 Cmd/Ctrl/Shift 多选以及原子化批量复制、删除和移动。
- 资源面板、本机导入和画布选择已接受音频；同一素材允许多次加入轨道。视频/音频的非正数时长按“元数据未知”处理，媒体元数据返回后只修正仍保持占位值的片段，避免覆盖用户裁剪；连续主视频片段会同步调整起点以保持相邻且不重叠。
- 现有关键帧、单文件处理、产物面板和单画面播放暂时通过 V2→V1 兼容视图工作；兼容视图只暴露主视频轨，不会压平或删除叠加/音频轨。
- 协议层新增结构化 RenderPlan V1。renderer 只能提交已枚举的片段、变换、音频、文本和输出参数，不能传入任意 FFmpeg filter 字符串。
- 主进程新增 FFmpeg filters/encoders 能力探测与缓存，并通过只读 IPC 暴露明确的功能门控；不同系统或受管 FFmpeg 构建不再被假定为能力完全一致。
- 旧 concat 自动产物只处理单条连续、无 V2 效果的纯视频轨。带空隙、图片、叠加、音频、变速或其它 V2 编辑的工程不会误走旧导出，真实合成预览与导出仍属于后续阶段。
