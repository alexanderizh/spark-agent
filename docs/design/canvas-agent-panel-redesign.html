三个注意点落实 v2 改进

  • ① 扁平化：参数 chip 去掉背景色（transparent → hover 浮灰），chip 高度 26→24px，头部 40→38px，消息 padding 14→10px
  • ① 扁平化：附件按钮文字→纯图标 24px，发送按钮 30→28px，输入区 padding 收紧
  • ② 宽阈值：MIN 320→300px，DEFAULT 380→400px，MAX 保持 560px，整体可拉伸范围 260px
  • ② 宽阈值：300px 窄态下参数行可横向滚动，不挤压输入框
  • ③ 完整性：补齐 v1 遗漏的 sendError / 动态 placeholder / 附件 chip / 问题卡片 / 空状态 / loading-error 覆盖
  • ③ 完整性：开发时需保留 pending 消息、草稿持久化、IME 组合判断、滚动控制等非视觉逻辑
