# 桌面端窗口激活策略

> 状态: 已落地 | 最后核对: 2026-07-20

SparkWork 桌面端包含主窗口和独立画布窗口。两个窗口都是普通顶层窗口，不建立父子关系，也不使用 `alwaysOnTop`。全局入口必须按用户意图区分目标窗口，不能依赖 `BrowserWindow.getAllWindows()` 的数组顺序推断窗口角色。

## 激活规则

| 入口 | 目标窗口 |
| --- | --- |
| 直接点击窗口 | 由操作系统聚焦被点击窗口 |
| 从主窗口打开画布 | 创建或复用画布窗口并聚焦 |
| macOS Dock 图标 | 有可见窗口时交给系统保持最近使用窗口；无可见窗口时恢复应用内最后聚焦窗口，兜底主窗口 |
| 状态栏图标、“打开主窗口”、新建会话、最近会话 | 主窗口 |
| 状态栏“打开画布” | 当前画布窗口；没有画布时不显示该菜单项 |
| 第二实例、业务深链、业务通知 | 主窗口 |
| 内部控制台、窗口缩放 | 当前或最近聚焦窗口，兜底主窗口 |

## 生命周期约束

- 主窗口关闭时保持原有行为：非退出流程只隐藏窗口。
- 画布窗口关闭时继续经过渲染进程的未保存修改确认。
- 窗口注册模块记录最后聚焦的有效应用窗口；窗口销毁后必须同步清除引用。
- 恢复窗口时依次处理最小化、隐藏和聚焦，避免只调用 `focus()` 导致窗口不可见。

## 回归检查

- 主窗口和画布同时可见时，点击 Dock 不得强制切换到另一窗口。
- 两个窗口均不可见时，点击 Dock 恢复最近使用窗口。
- 状态栏新建或打开会话时，主窗口必须显示在前，事件不得只发送到后台主窗口。
- 更新确认弹窗必须绑定主窗口，不得随机绑定画布窗口。
