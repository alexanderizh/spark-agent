# 普通会话与画布会话的可见性边界

> 状态: 已落地 | 最后核对: 2026-07-30

普通会话侧边栏和会话输入器的项目选择器只展示普通项目与普通会话。画布项目及其
Agent 会话继续保存在同一套 workspace/session 数据中，但只在画布工作区内访问，不在
普通会话入口重复展示。

## 判断依据

主进程以 `canvas_projects.root_path` 与 `workspaces.root_path` 的规范化路径关联作为权威
判断，并在 `WorkspaceInfo.canvasProjectId` 中返回关联结果。正常运行时渲染端以该显式
标记为准，不根据项目显示名称或默认 `canvas-projects` 目录猜测类型，因此自定义存放
目录下的画布项目也能正确过滤。

开发热更新或旧版本主进程尚未提供 `canvasProjectId` 字段时，渲染端只兼容匹配画布自动
生成的严格目录后缀 `-canvas_project_<时间标识>_<随机标识>`；一旦主进程明确返回
`canvasProjectId: null`，该兼容判断不再启用。

## 展示规则

- 输入器项目选择器分页加载并展示全部未归档普通项目，不再限制最近 5 个或单次请求上限。
- 项目列表独立滚动；「选择新项目」和「不需要项目」固定在菜单底部。
- Git worktree 仍跟随基础项目，不作为独立可选项目。
- 画布项目不出现在输入器项目选择器或侧边栏项目筛选菜单。
- 关联到画布 workspace 的会话不出现在侧边栏的项目、日期、状态和无分组视图。
- 过滤只影响普通会话 UI，不删除项目、workspace、会话或事件数据。
