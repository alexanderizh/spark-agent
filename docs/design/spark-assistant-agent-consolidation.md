# Spark助手内置 Agent 合并设计

> 状态: 已落地 | 最后核对: 2026-07-27

## 目标

将原「平台管理」与「全栈编码 Agent」合并为用户可直接选择的单一内置 Agent「Spark助手」，减少选择成本，同时保留平台管理和完整软件开发能力。画布助手不在本次合并范围内。

## 稳定标识与兼容策略

- Spark助手继续使用 `platform-manager-agent` 作为稳定 ID，避免修改聊天、画布、团队和会话创建中的默认回退逻辑。
- 原全栈编码 Agent `93785cf1-d570-4a2a-8919-108fbf7f39c3` 的 Skills、Rules、MCP 引用会合并到 Spark助手。
- 数据迁移会改写旧 Agent 在会话、定时任务、团队、工作流、画布快照、记忆和运行时设置中的引用，然后删除旧内置 Agent 行。
- 历史消息事件保留发送时的 Agent 快照，不改写已经展示给用户的历史身份文本。

## 运行配置

Spark助手使用 Claude SDK、`claude-auto-edits` 默认权限和 `high` 推理强度。统一提示词按任务意图路由：

- 平台配置任务调用 `platform-manager` Skill 与 `mcp__spark_platform__*` 工具。
- 软件开发任务执行需求理解、影响分析、实现、测试和交付流程。
- 搜索、浏览器、内容生产、前端设计和调试等能力通过 Skill 渐进式加载，避免把全部技能说明一次性注入上下文。

MCP 仍由会话运行时按可用性统一挂载，不恢复旧的 Agent 级 MCP Allow-list 行为。

## 数据迁移边界

迁移只合并平台管理和全栈编码两个内置 Agent，不修改 `canvas-assistant-agent`。若用户已把原全栈 Agent 绑定到自定义团队、工作流、定时任务或 Agent 记忆，引用会切换到 Spark助手；发生同名记忆冲突时保留两条记录，并给原全栈记忆追加来源后缀。
