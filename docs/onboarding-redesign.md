# 新手引导改版设计说明

> 状态: 已落地 | 最后核对: 2026-07-12

本次改版将安装后新手引导定位为桌面应用的配置向导，而不是营销式欢迎页。核心目标是让用户在 3 分钟内完成模型来源选择、服务商配置、助手模板创建和第一次对话，并在不强迫操作的前提下了解画布、Skill 和多媒体模型的使用入口，同时保证浅色与暗色主题下所有文字、输入框和视觉辅助区都有足够对比度。

## 设计要点

- 左侧步骤栏使用 Spark Agent 应用图标作为品牌锚点，步骤状态只表达当前进度，不承载额外说明。
- 主内容区保留单任务焦点：每一步只出现当前决策所需的表单、选项或结果。
- 模型来源页将 Spark 账号作为首选主操作，第三方模型与本机 AI 工具收敛为次级行入口，只保留用户做决策所需的文案。
- Spark 账号、第三方模型与本机 AI 工具三个接入页均在内容顶部提供“切换模型方式”入口，不依赖左侧步骤栏也能返回重选。
- 登录保留“密码 / 验证码”两种认证方式；邮箱与手机号由统一账号框自动识别并选择邮件或短信接口。注册同样根据账号输入自动切换邮箱或手机号流程，不再要求用户手动选择。
- 引导页认证输入框使用单层边框，底部辅助操作与登录/注册切换保持同一行；“跳过本步”使用分割线文字按钮，减少额外按钮层级。
- 邮箱注册字段采用单列顺序布局，依次填写验证码、密码、确认密码和可选邀请码；确认密码只做客户端一致性校验，注册接口仍提交单个密码字段。
- 认证账号输入使用单一文本输入层，避免自动补全组件的搜索层与选中层重叠显示。
- 认证输入组件必须透传表单的 `value` / `onChange`；验证码发送、登录注册提交和图片验证码刷新在异步请求完成前均需锁定，避免双击产生重复请求。
- 右侧视觉区按步骤切换 onboarding 海报资产，整体采用更扁平的容器层级，避免代码动画和悬浮模块感抢走主流程注意力。
- 模型配置页的服务商选项显示服务商 logo、名称和默认模型，降低长列表识别成本。
- 原“高级设置”改为“URL 和模型设置”，避免用户误以为里面是复杂或危险配置。
- 第一次对话之后新增 3 个可跳过的纯讲解步骤：画布使用、Skill 能力扩展、多媒体模型在对话和画布中的使用。
- 用户点击“稍后再说”或以关闭窗口 / 刷新等方式离开未完成的引导时，均视为已跳过并写入完成标记；下次启动不再自动打开引导。
- 所有背景、文字、边框、提示和输入控件使用项目主题变量，避免暗色模式下文字不可见。

## 验收重点

- 浅色和暗色主题下，欢迎页、模型来源页、第三方服务商页、连接测试页、助手模板页、第一次对话页、画布教学页、Skill 教学页、多媒体教学页均应可读。
- 服务商下拉列表每一项应带有服务商图标，当前服务商摘要卡也应展示图标。
- 右侧视觉辅助区应随步骤变化，不再是所有步骤共用同一张占位卡，并且要点文本不能遮挡主操作区。
- 移动或窄窗口下步骤栏隐藏，插画上移，文本与按钮不应重叠。
- 登录表单底部应保留明确留白；浅色与暗色主题下，Tab、输入框、主次按钮、禁用态和焦点态均应清晰可辨。
- 独立认证页与引导页嵌入认证共用账号识别和接口选择逻辑；输入手机号走短信流程，输入邮箱走邮件流程，短信能力关闭时不得误切换。
- 跳过引导后重启应用，不应再次自动进入新手引导；设置页“重新打开新手引导”仍应可清除标记并进入引导页。
