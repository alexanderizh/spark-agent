# 新手引导改版设计说明

> 状态: 已落地 | 最后核对: 2026-06-22

本次改版将安装后新手引导定位为桌面应用的配置向导，而不是营销式欢迎页。核心目标是让用户在 3 分钟内完成模型来源选择、服务商配置、助手模板创建和第一次对话，同时保证浅色与暗色主题下所有文字、输入框和插画区域都有足够对比度。

## 设计要点

- 左侧步骤栏使用 Spark Agent 应用图标作为品牌锚点，步骤状态只表达当前进度，不承载额外说明。
- 主内容区保留单任务焦点：每一步只出现当前决策所需的表单、选项或结果。
- 右侧视觉区按步骤切换 onboarding 插画资产，并叠加当前步骤摘要，让每一页都有不同的空间感和状态反馈。
- 模型配置页的服务商选项显示服务商 logo、名称和默认模型，降低长列表识别成本。
- 原“高级设置”改为“URL 和模型设置”，避免用户误以为里面是复杂或危险配置。
- 所有背景、文字、边框、提示和输入控件使用项目主题变量，避免暗色模式下文字不可见。

## 验收重点

- 浅色和暗色主题下，欢迎页、模型来源页、第三方服务商页、连接测试页、助手模板页、第一次对话页均应可读。
- 服务商下拉列表每一项应带有服务商图标，当前服务商摘要卡也应展示图标。
- 右侧插画应随步骤变化，不再是所有步骤共用同一张占位卡。
- 移动或窄窗口下步骤栏隐藏，插画上移，文本与按钮不应重叠。
