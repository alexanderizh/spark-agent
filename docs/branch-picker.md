# 分支选择器

> 状态: 已落地 | 最后核对: 2026-08-31

会话编辑器与右上角 Git 悬浮面板中的分支选择入口共享同一套分支数据规则：

- 本地分支与远程分支分组显示。
- 每组按分支头提交的提交者时间倒序排列，提交越新的分支越靠前；名称用于同一时间下的稳定排序。
- 远程分支以 `remote/name` 展示。首次选择时创建对应的本地跟踪分支；若同名本地分支已存在，则直接切换到该本地分支。
- `Fetch` 执行 `git fetch --prune`，完成后刷新列表，同时移除远程已删除分支的陈旧引用。
- Git 推送沿用仓库配置的 push remote；没有 upstream 的本地新分支会直接以本地分支名创建远端同名分支并建立 upstream。编辑器同步对已有 upstream 的分支保持“先拉取后推送”。
- 没有新版分支详情的旧缓存仍按本地分支处理，保持向后兼容。

这里的“最近活跃”使用 Git 可可靠查询的分支头提交时间。Git 不保存跨环境稳定的“最后一次在界面操作该分支”的时间，因此不使用弹窗点击时间作为排序依据。
